# HRCP-KKU DFD Mermaid Set

ชุดแผนภาพ Data Flow Diagram (DFD) นี้จัดทำเพื่ออธิบายภาพรวมการไหลของข้อมูลในระบบ HRCP-KKU แบบสองภาษา (ไทย+อังกฤษ) โดยเน้นรูปแบบขาวดำคลาสสิก อ่านง่าย และพร้อมใช้งานในเอกสารรายงานหรือการนำเสนอเชิงวิชาการ.

| file | purpose | suggested report caption |
|---|---|---|
| dfd-00-context.mmd | แสดงขอบเขตระบบและผู้มีส่วนเกี่ยวข้องภายนอก (Guest, Applicant, Admin, Scheduler, Email Service, External HR) | แผนภาพ DFD ระดับบริบท (Context) ของระบบ HRCP-KKU |
| dfd-01-level1-overview.mmd | ภาพโครงหลักของ P1-P9 (แบบเบา ลดเส้นซ้อน) | แผนภาพ DFD ระดับ 1 (ภาพหลัก) สำหรับนำทางไปภาพย่อย |
| dfd-01a-level1-request-domain.mmd | แยกกลุ่ม Request Domain (P1-P4) พร้อม data stores | แผนภาพ DFD ระดับ 1A: กระบวนการคำร้องและการสื่อสารผล |
| dfd-01b-level1-admin-domain.mmd | แยกกลุ่ม Admin Domain (P5-P8) | แผนภาพ DFD ระดับ 1B: กระบวนการฝั่งผู้ดูแลระบบ |
| dfd-01c-level1-scheduler-domain.mmd | แยกกลุ่ม Scheduler Domain (P9) | แผนภาพ DFD ระดับ 1C: งานตรวจหมดอายุและแจ้งเตือน |
| dfd-02-auth-level2.mmd | รายละเอียดกระบวนการยืนยันตัวตนและสิทธิ์ผู้ใช้ | แผนภาพ DFD ระดับ 2: งานยืนยันตัวตน |
| dfd-03-academic-level2.mmd | รายละเอียดคำร้องวิชาการและการติดตามสถานะ | แผนภาพ DFD ระดับ 2: งานคำร้องวิชาการ |
| dfd-04-position-level2.mmd | รายละเอียดคำร้องตำแหน่งและการอนุมัติ | แผนภาพ DFD ระดับ 2: งานคำร้องตำแหน่ง |
| dfd-05-petition-level2.mmd | รายละเอียดงานคำร้องทั่วไป (Petitions) | แผนภาพ DFD ระดับ 2: งานคำร้องทั่วไป |
| dfd-06-staff-management-level2.mmd | รายละเอียดการจัดการข้อมูลบุคลากร | แผนภาพ DFD ระดับ 2: งานจัดการบุคลากร |
| dfd-07-file-management-level2.mmd | รายละเอียดการอัปโหลด/จัดเก็บ/เรียกใช้ไฟล์เอกสาร | แผนภาพ DFD ระดับ 2: งานจัดการไฟล์ |
| dfd-08-user-management-level2.mmd | รายละเอียดการจัดการผู้ใช้และบทบาท | แผนภาพ DFD ระดับ 2: งานจัดการผู้ใช้ |
| dfd-09-settings-notifications-level2.mmd | รายละเอียดการตั้งค่าระบบและการแจ้งเตือน | แผนภาพ DFD ระดับ 2: งานตั้งค่าและแจ้งเตือน |

## วิธีใช้งาน

- เปิดไฟล์ .mmd ด้วย Mermaid Preview ใน VS Code เพื่อดูแผนภาพทันที.
- ใช้ลำดับแนะนำ: dfd-00-context.mmd -> dfd-01-level1-overview.mmd -> dfd-01a/01b/01c เพื่อค่อยๆ ลงรายละเอียดโดยไม่ให้ภาพแน่นเกินไป.
- อ้างอิงไฟล์ระดับ 2 ตามโมดูลที่ต้องการอธิบายเชิงลึกในรายงาน.

## ขอบเขต

แผนภาพชุดนี้เป็นแบบ abstraction เพื่อสื่อสารโครงสร้างการไหลข้อมูลในระดับวิเคราะห์ระบบ ไม่ลงรายละเอียดเชิง implementation ภายในโค้ด และมี dependency ด้านสถานะธุรกิจว่าเส้นทางส่งต่อไปภายนอกจะเกิดเมื่อเงื่อนไข COMPLETED_PASS + not expired เป็นจริงเท่านั้น.
