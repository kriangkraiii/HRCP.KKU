# KKU Digital ID (.p12) Test Certificates for Development

ชุดไฟล์ใบรับรองดิจิทัลจำลองสำหรับนักพัฒนา (Developer) ใช้ทดสอบระบบ e-Sign ของมหาวิทยาลัยขอนแก่น

---

### 1. ใบรับรองปกติ (Valid Certificate) — สำหรับทดสอบการลงนามทั่วไป
- **ไฟล์:** `dev-certs/kku-digital-id-dev.p12`
- **Digital ID Password:** `KkuDev1234!`
- **ชื่อผู้ลงนาม (CN):** ผศ.ดร.เกรียงไกร เกียรติบูรณกุล
- **ผู้ออกใบรับรอง (Issuer):** ODT KKU CA, Khon Kaen University
- **อายุการใช้งาน:** 2 ปี (ยังไม่หมดอายุ)
- **การทดสอบ:**
  1. ไปที่เมนู **ลายเซ็นของฉัน** (`/esign/my-signatures`)
  2. เลือกอัปโหลดไฟล์ `kku-digital-id-dev.p12`
  3. ใส่ Digital ID Password: `KkuDev1234!`
  4. กดปุ่ม **"ตรวจสอบความถูกต้อง"** -> แสดงการ์ดสีเขียว ตรวจสอบสำเร็จ
  5. กดปุ่ม **"ติดตั้ง Digital Certificate"**
  6. ทดลองเปิดหน้าลงนามเอกสาร (`/esign/sign/{id}`) -> สามารถเลือกลายเซ็นและกดลงนามได้ทันที (One-Click Sign)

---

### 2. ใบรับรองหมดอายุ (Expired Certificate) — สำหรับทดสอบการแจ้งเตือนและการสกัดกั้น
- **ไฟล์:** `dev-certs/kku-digital-id-expired-dev.p12`
- **Digital ID Password:** `KkuDev1234!`
- **ชื่อผู้ลงนาม (CN):** ผศ.ดร.เกรียงไกร เกียรติบูรณกุล (หมดอายุ)
- **สถานะ:** หมดอายุแล้ว (Valid To สิ้นสุดไปเมื่อ 1 วันก่อน)
- **การทดสอบ:**
  1. ทดสอบนำไฟล์นี้ไปติดตั้งในหน้า `/esign/my-signatures` แล้วกดตรวจสอบ -> ระบบจะแจ้งเตือนสีแดงทันทีว่า *"ใบรับรองดิจิทัลนี้หมดอายุแล้วเมื่อ..."* และไม่อนุญาตให้กดติดตั้ง
  2. หากมีใบรับรองหมดอายุอยู่ในระบบ หน้า `/esign/sign/{id}` จะขึ้นกล่องเตือนสีแดง *"ใบรับรอง Digital ID (.p12) หมดอายุแล้ว"* และซ่อนปุ่มยืนยันลงนามทั้งหมด

---

### การสร้างใหม่ (Regenerate)
หากต้องการสร้างไฟล์ชุดใหม่ สามารถสั่งรันคำสั่ง:
```bash
./mvnw test -Dtest="DevCertGeneratorTest"
```
