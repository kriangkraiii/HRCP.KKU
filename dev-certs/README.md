## 🛠️ ขั้นตอนการทดสอบใช้งาน

### 1. การติดตั้งใบรับรอง (Positive Test)
1. ล็อกอินเข้าสู่ระบบด้วยบัญชีที่ต้องการทดสอบ (เช่น Dean, Head, Applicant, Admin)
2. ไปที่เมนู **ลายเซ็นของฉัน** (`/esign/my-signatures`)
3. ในส่วน **"ติดตั้ง Digital Certificate (.p12)"** ให้เลือกไฟล์ `.p12` ที่ตรงกับบทบาทนั้น
4. ระบุ Digital ID Password: `KkuDev1234!`
5. กดปุ่ม **"ตรวจสอบความถูกต้อง"** -> แสดงการ์ดสีเขียวพร้อมข้อมูลผู้ถือใบรับรองและวันหมดอายุ
6. กดปุ่ม **"ติดตั้ง Digital Certificate"**
7. ไปที่หน้ารายการรอลงนาม (`/esign/inbox`) หรือเปิดเอกสาร (`/esign/sign/{id}`) -> สามารถเลือกลายเซ็นและกด **"ยืนยันการลงนาม (One-Click Sign)"** ได้ทันที ระบบจะประทับตรารับรอง PAdES Cryptographic Signature ลงใน PDF พร้อมระบุชื่อตามใบรับรอง

### 2. การทดสอบกรณีใบรับรองหมดอายุ (Negative Test)
1. ใช้ไฟล์ `dev-certs/kku-digital-id-expired-dev.p12` (Password: `KkuDev1234!`)
2. ทดสอบอัปโหลดในหน้า `/esign/my-signatures` แล้วกดตรวจสอบ -> ระบบจะแจ้งเตือนสีแดงทันทีว่า *"ใบรับรองดิจิทัลนี้หมดอายุแล้ว"* และไม่อนุญาตให้ติดตั้ง
3. หากผู้ลงนามมีใบรับรองที่หมดอายุ หน้า `/esign/sign/{id}` จะแสดงข้อความแจ้งเตือนสีแดงและซ่อนปุ่มลงนามทันที

## 🔄 การสร้างไฟล์ชุดใหม่ (Regenerate All Certificates)

หากต้องการสร้างไฟล์ใบรับรองทั้งหมดขึ้นมาใหม่ สามารถรันคำสั่ง Maven Test ได้ทันที:

```bash
./mvnw test -Dtest="DevCertGeneratorTest"
```

สคริปต์จะทำการ Generate ไฟล์กุญแจและใบรับรอง X.509 v3 พร้อมบันทึกไฟล์ `.p12` ใหม่ทั้งหมดลงในโฟลเดอร์ `dev-certs/` ทั้งสองตำแหน่งโดยอัตโนมัติ
