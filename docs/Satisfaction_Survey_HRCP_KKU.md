# แบบประเมินความพึงพอใจของผู้ใช้งานระบบ

## ระบบเอกสารและการติดตามผลการยื่นขอกำหนดตำแหน่งทางวิชาการ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น

## (Document and Tracking System for Academic Promotion, College of Computing, Khon Kaen University — HRCP.KKU)

---

แบบสอบถามนี้จัดทำขึ้นโดยมีวัตถุประสงค์เพื่อประเมินคุณภาพและรวบรวมข้อเสนอแนะจากการทดลองใช้งานระบบเอกสารและการติดตามผลการยื่นขอกำหนดตำแหน่งทางวิชาการ (HRCP.KKU) และนำข้อมูลที่ได้มาปรับปรุงแก้ไขพัฒนาระบบให้ตอบสนองต่อความต้องการของผู้ใช้งาน เพื่อให้การใช้งานเกิดประโยชน์สูงสุด

การยินยอมให้กับรวบรวมข้อมูล ผู้จัดทำโครงงานจะเก็บรวบรวมข้อมูลคำตอบของท่านเพื่อใช้ในการวิเคราะห์และปรับปรุงโครงงานนี้เท่านั้น ข้อมูลของท่านจะถูกเก็บเป็นความลับและไม่ถูกนำไปเผยแพร่ในลักษณะที่ระบุตัวตนได้

☐ ข้าพเจ้ายินยอม ให้ผู้จัดทำโครงงานเก็บรวบรวม และใช้ข้อมูลจากแบบสอบถามนี้เพื่อวัตถุประสงค์ดังกล่าว

---

## ตอนที่ 1 ข้อมูลทั่วไป

สถานะของผู้ประเมิน :

☐ อาจารย์/บุคลากรสายวิชาการ (ผู้ยื่นคำขอ)

☐ เจ้าหน้าที่ทรัพยากรบุคคล/ผู้ดูแลระบบ

☐ ผู้บริหาร/คณะกรรมการ

☐ บุคคลทั่วไป/อื่น ๆ

ท่านทดลองใช้งานระบบในบทบาทใดเป็นหลัก :

☐ ทดลองในมุมมอง "ผู้ยื่นคำขอ" (สร้างคำร้อง, กรอกเอกสาร, ติดตามสถานะ)

☐ ทดลองในมุมมอง "ผู้ดูแลระบบ" (ตรวจสอบคำร้อง, อัพเดทสถานะ, สร้างเอกสาร)

☐ ทดลองทั้งสองบทบาท

ท่านเคยมีประสบการณ์ในกระบวนการยื่นขอกำหนดตำแหน่งทางวิชาการ (แบบกระดาษ) มาก่อนหรือไม่ :

☐ เคย (ในฐานะผู้ยื่นคำขอ)

☐ เคย (ในฐานะเจ้าหน้าที่ผู้ดำเนินการ)

☐ เคย (ทั้งสองฐานะ)

☐ ไม่เคย

## ตอนที่ 2 แบบสอบถามความพึงพอใจของผู้ใช้งาน

**คำชี้แจง :** โปรดระบุความพึงพอใจต่อการใช้งานระบบ โดยพิจารณาจาก Mockup หรือเว็บแอปพลิเคชันที่ได้ทดลองใช้งาน โดยทำเครื่องหมาย ✓ ลงใน ☐ ซึ่งระดับประมาณค่าประสิทธิภาพและคุณค่า แบ่งเป็น 5 ระดับ ดังนี้

> ระดับดีมาก = 5, ระดับดี = 4, ระดับปานกลาง = 3, ระดับพอใช้ = 2, ระดับปรับปรุง = 1

---

### ส่วนที่ 2.1 สำหรับผู้ทดลองใช้งานในบทบาท "ผู้ยื่นคำขอ" (Applicant)

(กรุณาข้ามส่วนนี้ หากท่านทดลองใช้งานเฉพาะบทบาทผู้ดูแลระบบ)

| รายการสอบถามการใช้งานระบบ | ระดับความพึงพอใจ |||||
|:---|:---:|:---:|:---:|:---:|:---:|
| | **5** | **4** | **3** | **2** | **1** |
| **1. ด้านการออกแบบและความชัดเจน** | | | | | |
| 1.1 การออกแบบหน้าจอมีความสวยงาม การจัดวางองค์ประกอบเหมาะสม และใช้งานง่าย | ☐ | ☐ | ☐ | ☐ | ☐ |
| 1.2 การเลือกใช้สี ฟอนต์ และไอคอน มีความสอดคล้องและเป็นเอกภาพทั่วทั้งระบบ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 1.3 ภาษาและข้อความที่ใช้ในระบบมีความชัดเจน สื่อความหมายได้ดี และเข้าใจง่าย | ☐ | ☐ | ☐ | ☐ | ☐ |
| 1.4 การแสดงข้อมูลคำร้องและเอกสาร (เช่น สถานะ, ไทม์ไลน์) มีความชัดเจนและเพียงพอต่อการตัดสินใจ | ☐ | ☐ | ☐ | ☐ | ☐ |
| **2. ด้านฟังก์ชันการทำงานและวัตถุประสงค์** | | | | | |
| 2.1 ขั้นตอนการเข้าสู่ระบบ (Login) และการยืนยันตัวตน (OTP) มีความสะดวกและปลอดภัย | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.2 ขั้นตอนการสร้างคำร้องและกรอกแบบฟอร์มเอกสาร มีความสะดวก ไม่ซับซ้อน | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.3 ระบบบันทึกฉบับร่างอัตโนมัติ (Auto Draft Save) ช่วยป้องกันการสูญหายของข้อมูลได้ดี | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.4 การติดตามสถานะคำร้องแบบ Real-time (Progress Bar, ไทม์ไลน์) มีความชัดเจนและเข้าใจง่าย | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.5 การแจ้งเตือนทางอีเมลเมื่อสถานะคำร้องเปลี่ยนแปลง มีประโยชน์ต่อการติดตามงาน | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.6 การอัปโหลดเอกสารประกอบ มีความสะดวกและรองรับประเภทไฟล์ได้เหมาะสม | ☐ | ☐ | ☐ | ☐ | ☐ |
| **3. ด้านความปลอดภัยและความน่าเชื่อถือ** | | | | | |
| 3.1 ระบบยืนยันตัวตน (รหัสผ่าน, OTP) ช่วยสร้างความน่าเชื่อถือและความมั่นใจในความปลอดภัย | ☐ | ☐ | ☐ | ☐ | ☐ |
| 3.2 การเข้าถึงข้อมูลและเอกสารมีการจำกัดสิทธิ์ตามบทบาทอย่างเหมาะสม (เห็นเฉพาะเอกสารที่เกี่ยวข้องกับตนเอง) | ☐ | ☐ | ☐ | ☐ | ☐ |
| **4. ภาพรวมของโครงงาน** | | | | | |
| 4.1 ระบบช่วยลดความยุ่งยากและความซับซ้อนในกระบวนการยื่นขอกำหนดตำแหน่งทางวิชาการได้ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4.2 ระบบช่วยลดความคลาดเคลื่อนในการกรอกข้อมูลและจัดเตรียมเอกสารได้ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4.3 หากระบบนี้เปิดให้บริการจริง ท่านจะเลือกใช้ระบบอิเล็กทรอนิกส์แทนการยื่นเอกสารกระดาษหรือไม่ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4.4 ท่านคิดว่าระบบนี้มีประโยชน์และอยากจะแนะนำให้เพื่อนร่วมงานหรือคณาจารย์ท่านอื่นได้ทดลองใช้งานหรือไม่ | ☐ | ☐ | ☐ | ☐ | ☐ |

### ส่วนที่ 2.2 สำหรับผู้ทดลองใช้งานในบทบาท "ผู้ดูแลระบบ" (Admin/Staff)

(กรุณาข้ามส่วนนี้ หากท่านทดลองใช้งานเฉพาะบทบาทผู้ยื่นคำขอ)

| รายการสอบถามการใช้งานระบบ | ระดับความพึงพอใจ |||||
|:---|:---:|:---:|:---:|:---:|:---:|
| | **5** | **4** | **3** | **2** | **1** |
| **1. ด้านการออกแบบและความชัดเจน** | | | | | |
| 1.1 การออกแบบหน้าจอผู้ดูแลระบบมีความเหมาะสม จัดวางองค์ประกอบชัดเจน และใช้งานง่าย | ☐ | ☐ | ☐ | ☐ | ☐ |
| 1.2 การเลือกใช้สี ฟอนต์ และไอคอน มีความสอดคล้องและเป็นเอกภาพทั่วทั้งระบบ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 1.3 ภาษาและข้อความที่ใช้ในระบบมีความชัดเจน สื่อความหมายได้ดี และเข้าใจง่าย | ☐ | ☐ | ☐ | ☐ | ☐ |
| 1.4 การแสดงข้อมูลรายการคำร้อง, Dashboard และสถิติ มีความชัดเจนและเพียงพอต่อการบริหารจัดการ | ☐ | ☐ | ☐ | ☐ | ☐ |
| **2. ด้านฟังก์ชันการทำงานและวัตถุประสงค์** | | | | | |
| 2.1 ขั้นตอนการตรวจสอบและอัพเดทสถานะคำร้อง มีความสะดวก ไม่ซับซ้อน | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.2 ระบบสร้างเอกสาร DOCX อัตโนมัติจากข้อมูลในระบบ ช่วยลดภาระงานได้อย่างมีประสิทธิภาพ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.3 การกรอกข้อมูลในแบบฟอร์มเอกสาร (ประเภท 2-8) และระบบ Auto-Fill ข้อมูลข้ามเอกสาร มีความสะดวก | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.4 การจัดการไฟล์เอกสาร (อัปโหลด, ดาวน์โหลด, ดาวน์โหลด ZIP) มีความสะดวกและครบถ้วน | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.5 ระบบแจ้งเตือนทางอีเมลอัตโนมัติ ช่วยให้การสื่อสารกับผู้ยื่นคำร้องมีประสิทธิภาพ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2.6 ระบบจัดการบุคลากร/กรรมการ (เพิ่ม, แก้ไข, ลบ) มีความสะดวกและตอบสนองความต้องการ | ☐ | ☐ | ☐ | ☐ | ☐ |
| **3. ด้านความปลอดภัยและความน่าเชื่อถือ** | | | | | |
| 3.1 ระบบการจัดการผู้ใช้งาน (สร้าง, แก้ไข, เปิด/ปิดบัญชี) มีความสะดวกและครบถ้วน | ☐ | ☐ | ☐ | ☐ | ☐ |
| 3.2 ระบบบันทึกประวัติการดำเนินงาน (Admin Log, Status History) ช่วยในการตรวจสอบย้อนหลังได้ดี | ☐ | ☐ | ☐ | ☐ | ☐ |
| **4. ภาพรวมของโครงงาน** | | | | | |
| 4.1 ระบบช่วยเพิ่มประสิทธิภาพในการบริหารจัดการกระบวนการขอกำหนดตำแหน่งทางวิชาการได้ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4.2 ระบบช่วยลดระยะเวลาในการดำเนินกระบวนการเมื่อเทียบกับระบบเอกสารกระดาษ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4.3 หากระบบนี้เปิดให้บริการจริง ท่านจะเลือกใช้ระบบนี้แทนกระบวนการเอกสารกระดาษหรือไม่ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4.4 ท่านคิดว่าระบบนี้มีประโยชน์และอยากจะแนะนำให้หน่วยงานอื่นนำไปประยุกต์ใช้หรือไม่ | ☐ | ☐ | ☐ | ☐ | ☐ |
