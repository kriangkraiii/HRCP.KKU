# แนวทางการเขียนข้อความบนหน้าจอ (CP ACAD)

ใช้กับข้อความทุกชนิดที่ผู้ใช้เห็น ได้แก่ หัวข้อ คำอธิบาย ปุ่ม placeholder ข้อความแจ้งเตือน และข้อความใน `alert()` / `confirm()`

## ภาษาและน้ำเสียง

- ใช้ **"ท่าน"** เมื่อเรียกผู้ใช้ ไม่ใช้ "คุณ"
- ใช้ **"เจ้าหน้าที่"** หรือ **"ผู้ดูแลระบบ"** แทน "แอดมิน"
- ใช้ **"ลงนาม"** แทน "เซ็น" ส่วน "ลายเซ็น" ที่เป็นคำนามใช้ได้
- ไม่ใช้คำพูดแบบสนทนา เช่น ครับ/ค่ะ, นะ, เลย, ง่ายๆ, มั้ย, ลอง, ติ๊ก (ให้ใช้ "ทำเครื่องหมาย"), ทีหลัง
- ไม่ใช้เครื่องหมาย `!`, ✓ หรือ emoji ในข้อความ
- ใช้ "เนื่องจาก" แทน "เพราะ" และขึ้นต้นคำขอด้วย "กรุณา"
- คำยืนยันใช้รูปแบบ **"ยืนยันการ…?"** ไม่ใช้ "คุณแน่ใจหรือไม่ว่า…"
- สะกดคำตามราชบัณฑิต เช่น **อัปเดต** และ **อัปโหลด**

## ภาษาอังกฤษ

- ใช้เฉพาะชื่อเฉพาะที่ไม่มีคำไทยใช้ เช่น Digital ID (.p12), KKU SSO, Scopus, PDF, OTP
- ไม่ต่อวงเล็บภาษาอังกฤษท้ายหัวข้อ เช่น ~~(E-Signature Inbox)~~ หรือ ~~(Admin)~~
- ไม่แสดงรายละเอียดทางเทคนิคให้ผู้ใช้เห็น เช่น ชื่อตัวแปรระบบ path ของไฟล์ หรือเวลาประมวลผล (ms)

## ความยาว และเมื่อใดควรใช้ปุ่ม (i)

| ชนิดข้อความ | ที่วาง |
|---|---|
| สิ่งที่ผู้ใช้ต้องทำ หรือต้องใช้ตัดสินใจ | บนหน้า สั้นไม่เกิน 1 บรรทัด |
| คำเตือนเรื่องที่ย้อนกลับไม่ได้ (ลบถาวร, หยุดการเวียนลงนาม) | บนหน้าเสมอ |
| ข้อความยินยอมและข้อกฎหมายที่ผู้ใช้ต้องยอมรับ | บนหน้าเสมอ ห้ามย่อเนื้อหา |
| เหตุผลของขั้นตอน นโยบาย หรือข้อกฎหมายประกอบ | ปุ่ม (i) |
| ข้อความที่ซ้ำกับหัวข้อ ป้าย หรือ placeholder | ลบออก |

## ปุ่ม (i)

Fragment อยู่ที่ `templates/academic/_info_tip.html` และทำงานผ่าน `static/js/info_tip.js` ซึ่ง `base_academic.html` โหลดไว้ทุกหน้าแล้ว

```html
<label class="form-label">
    รหัสผ่าน Digital ID
    <span th:replace="~{academic/_info_tip :: tip('ใช้ปลดล็อกใบรับรองเฉพาะครั้งนี้ ระบบไม่เก็บรหัสผ่านไว้')}"></span>
</label>
```

- เนื้อหาใน popover เป็นข้อความล้วน ไม่รองรับ HTML
- ใช้เมาส์ แป้นพิมพ์ (Tab, Enter, Esc) และหน้าจอสัมผัสได้
- ใช้ได้เฉพาะหน้าที่อยู่ใน `base_academic` หน้า guest และหน้า error ไม่ได้โหลด Bootstrap popover ไว้
