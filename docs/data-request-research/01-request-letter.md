## ๑. เรื่องเดิมและวัตถุประสงค์

ตามที่วิทยาลัยการคอมพิวเตอร์ได้พัฒนาระบบสารสนเทศเพื่อสนับสนุนการขอกำหนดตำแหน่งทางวิชาการ
(ระบบ HRCP-KKU-Academic) เพื่อรองรับการยื่นคำขอตำแหน่งผู้ช่วยศาสตราจารย์ รองศาสตราจารย์
และศาสตราจารย์ ผ่านระบบอิเล็กทรอนิกส์นั้น

ปัจจุบันผู้ยื่นคำขอต้อง **พิมพ์รายการผลงานวิชาการของตนเองซ้ำด้วยมือ** ลงในแบบฟอร์ม ก.พ.ว. มข.
หลายฉบับ ทั้งที่ข้อมูลดังกล่าวมีอยู่แล้วในระบบฐานข้อมูลงานวิจัยของคณะ/มหาวิทยาลัย
ส่งผลให้เกิดภาระงานซ้ำซ้อน ข้อมูลไม่ตรงกันระหว่างระบบ และเสี่ยงต่อความผิดพลาด
ในเอกสารที่ใช้ประกอบการพิจารณา

วิทยาลัยจึงมีความประสงค์ขอเชื่อมโยงข้อมูลผลงานวิจัยจากระบบของท่าน
เพื่อ **เติมข้อมูลในแบบ ก.พ.ว. ให้ผู้ยื่นคำขออัตโนมัติ** โดยผู้ยื่นเป็นผู้ตรวจทาน
ยืนยัน และแก้ไขได้ก่อนส่งคำขอทุกครั้ง

## ๒. แบบฟอร์มที่จะได้ประโยชน์

ข้อมูลที่ขอจะถูกใช้เติมแบบฟอร์มในระบบ ๕ ฉบับ ได้แก่

| ฉบับ | ชื่อแบบฟอร์ม | ข้อมูลหลักที่ต้องใช้ |
|---|---|---|
| ๑ | แบบ ก.พ.ว. มข. ๐๓ (ประวัติและผลงาน) | รายชื่อผลงานวิจัย/ตำรา/หนังสือ, Scopus, h-index, ควอไทล์, โครงการวิจัยและแหล่งทุน |
| ๔ | บันทึกรับรองผลงานทางวิชาการ (วิทยานิพนธ์) | ผลงานที่เป็นส่วนหนึ่งของวิทยานิพนธ์ ป.โท/ป.เอก |
| ๖ | บันทึกข้อความจริยธรรมการวิจัย (Exemption) | ชื่อผลงาน, สถานะผู้ประพันธ์, Impact Factor, ฐานข้อมูล, การรับรองจริยธรรม |
| ๗ | แบบฟอร์มตรวจสอบคุณสมบัติ (Checklist) | ประเภทผลงาน, สถานะการเผยแพร่, หลักฐานประกอบ |
| ๙ | ลักษณะการมีส่วนร่วมในผลงาน | ผู้ประพันธ์อันดับแรก/บรรณกิจ, สัดส่วนการมีส่วนร่วม, สิทธิบัตร, ทุนวิจัย |

## ๓. สิ่งที่ขอความอนุเคราะห์ (๓ ข้อ)

### ๓.๑ ข้อมูล
ขอข้อมูลตามรายการใน **เอกสารแนบ ๑ — พจนานุกรมข้อมูล (Data Dictionary)**
ซึ่งจำแนกเป็น ๑๔ ตาราง และระบุระดับความจำเป็นของแต่ละฟิลด์ไว้ ๓ ระดับ คือ

- **จำเป็น (M)** — หากไม่มี ระบบจะเติมข้อมูลอัตโนมัติไม่ได้เลย
- **ควรมี (R)** — หากไม่มี ผู้ยื่นคำขอยังต้องกรอกช่องนั้นเอง
- **เผื่ออนาคต (O)** — ยังไม่ใช้ในทันที แต่ขอไว้เพื่อไม่ต้องขอข้อมูลซ้ำ

**ขอบเขต:** บุคลากรสายวิชาการทั้งคณะ ผลงานย้อนหลัง ๑๐ ปี
(ยกเว้นผลงานที่เคยใช้เสนอขอตำแหน่งมาก่อน ขอโดยไม่จำกัดปี)

**ประเด็นสำคัญ ๓ ข้อที่ขอเน้นเป็นพิเศษ** เนื่องจากมักไม่มีในระบบฐานข้อมูลงานวิจัยทั่วไป
แต่เป็นข้อมูลที่แบบ ก.พ.ว. บังคับ

1. **รหัสพนักงาน (employee code)** — จำเป็นสำหรับจับคู่ข้อมูลผลงานเข้ากับบัญชีผู้ใช้ในระบบ
   หากไม่มี ขอเป็นอีเมล @kku.ac.th แทน
2. **สถานะผู้ประพันธ์** — ผู้ประพันธ์อันดับแรก (First author) / ผู้ประพันธ์บรรณกิจ
   (Corresponding author) / ผู้มีส่วนสำคัญทางปัญญา ต้องแยกเป็นข้อมูลรายผลงานรายคน
   หากระบบต้นทางไม่เก็บสามข้อนี้ แบบฟอร์มฉบับที่ ๖ และ ๙ จะยังเติมอัตโนมัติไม่ได้
3. **ประวัติการนำผลงานไปใช้เสนอขอตำแหน่ง** — ผลงานชิ้นใดเคยใช้เสนอขอตำแหน่งแล้ว
   ในปีใด ระดับคุณภาพเท่าใด (มักเป็นข้อมูลฝั่งงานบุคคล ไม่ใช่ฝั่งงานวิจัย)

### ๓.๒ ช่องทางการเชื่อมโยงข้อมูล
ขอให้ท่านเลือกช่องทางที่สะดวก ตามรายละเอียดใน **เอกสารแนบ ๒ — ข้อกำหนดการส่งมอบข้อมูล**
โดยวิทยาลัยยินดีรับได้ทุกรูปแบบ เรียงตามลำดับที่จะเป็นประโยชน์สูงสุด

1. เชื่อมต่อผ่าน REST API (JSON)
2. เปิดสิทธิ์อ่าน (read-only) มุมมองฐานข้อมูลที่ตกลงร่วมกัน
3. ส่งไฟล์อัตโนมัติรายคืนผ่าน SFTP
4. ส่งไฟล์ Excel/CSV เป็นครั้ง ๆ ตามแบบฟอร์มที่วิทยาลัยจัดเตรียมไว้ให้

### ๓.๓ ผู้ประสานงาน
ขอทราบชื่อและช่องทางติดต่อของ

- ผู้ประสานงานด้านเทคนิค (ผู้ดูแลระบบต้นทาง)
- ผู้มีอำนาจอนุมัติการเข้าถึงข้อมูล
- เอกสาร/แบบฟอร์มที่วิทยาลัยต้องดำเนินการเพิ่มเติมตามระเบียบของท่าน (ถ้ามี)

## ๔. การคุ้มครองข้อมูลส่วนบุคคล

วิทยาลัยขอยืนยันแนวปฏิบัติดังนี้

- **วัตถุประสงค์จำกัด** — ใช้เพื่อเติมคำขอกำหนดตำแหน่งทางวิชาการของเจ้าของข้อมูลเอง
  ไม่นำไปใช้ประเมิน จัดอันดับ หรือเปิดเผยต่อบุคคลอื่น
- **ผู้เข้าถึง** — เจ้าของข้อมูล และเจ้าหน้าที่งานบุคคลที่ได้รับมอบหมายเท่านั้น
- **การรับส่ง** — เข้ารหัสด้วย TLS ไม่ส่งผ่านอีเมลแบบไม่เข้ารหัส
- **ไม่ขอข้อมูลอ่อนไหว** — ไม่ขอเลขบัตรประจำตัวประชาชนฉบับเต็ม เงินเดือน หรือข้อมูลสุขภาพ
- วิทยาลัยพร้อมจัดทำ **ข้อตกลงการใช้ข้อมูล (Data Use Agreement)** และแบบแสดงความยินยอม
  ของเจ้าของข้อมูล หากท่านกำหนด

## ๕. กำหนดเวลาที่เสนอ

| ระยะ | กิจกรรม | ระยะเวลา |
|---|---|---|

| ๒ | ส่งข้อมูลตัวอย่าง ๕–๑๐ รายการ (ปิดบังชื่อได้) เพื่อทดสอบโครงสร้าง | ภายใน ๒ สัปดาห์ถัดไป |
