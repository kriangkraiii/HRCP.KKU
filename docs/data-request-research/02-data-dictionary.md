# เอกสารแนบ ๑ — พจนานุกรมข้อมูล (Data Dictionary)

**ข้อมูลผลงานวิจัยและผลงานทางวิชาการที่ขอความอนุเคราะห์**
ระบบ HRCP-KKU-Academic · วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น

---

## วิธีอ่านเอกสารนี้

### คอลัมน์
| คอลัมน์ | ความหมาย |
|---|---|
| **ฟิลด์** | ชื่อฟิลด์ที่วิทยาลัยขอ (ชื่อเชิงตรรกะ — ท่าน**ไม่จำเป็น**ต้องตั้งชื่อคอลัมน์ในระบบของท่านตรงกัน เพียงระบุว่าคอลัมน์ของท่านชื่ออะไรตรงกับฟิลด์นี้) |
| **ชื่อไทย** | ความหมายในภาษาไทย |
| **ชนิด** | ชนิดข้อมูลและรูปแบบที่ขอ |
| **จำเป็น** | ระดับความจำเป็น (ดูด้านล่าง) |
| **เติมแบบ ก.พ.ว.** | ฟิลด์นี้ถูกนำไปเติมช่องใดในแบบฟอร์มฉบับใด (เลขฉบับ ๑/๔/๖/๗/๙) |

### ระดับความจำเป็น
| รหัส | ความหมาย |
|---|---|
| **M** | **จำเป็น** — ไม่มีแล้วเติมข้อมูลอัตโนมัติไม่ได้ |
| **R** | **ควรมี** — ไม่มีแล้วผู้ยื่นคำขอต้องกรอกช่องนั้นเองต่อไป |
| **O** | **เผื่ออนาคต** — ยังไม่ใช้ทันที ขอไว้เพื่อไม่ต้องขอข้อมูลซ้ำภายหลัง |

# ภาคผนวก — ข้อมูลที่วิทยาลัย **ไม่** ขอจากคณะ

เพื่อความชัดเจนของขอบเขต ช่องต่อไปนี้ในแบบ ก.พ.ว. เป็นข้อมูลที่ผู้ยื่นคำขอ
หรือเจ้าหน้าที่กรอกเองในระบบ **ไม่ต้องส่งมาให้**

- **ข้อมูลธุรการของเอกสาร** — เลขที่บันทึก, วันที่ลงนาม, ชื่อ/ตำแหน่งคณบดี,
  ชื่อ/ตำแหน่งเจ้าหน้าที่บุคคล, จำนวนชุดเอกสารที่แนบ
- **ข้อมูลที่ผู้ยื่นต้องยืนยันด้วยตนเอง** — ตำแหน่งที่ประสงค์จะขอ, วิธีการพิจารณา
  (ปกติ/พิเศษ), สาขาวิชาที่ขอ, การรับรองจริยธรรมและจรรยาบรรณ
- **ข้อมูลการสอน** — รายวิชาที่สอน ระดับ ภาคการศึกษา จำนวนชั่วโมง/สัปดาห์
  (ระบบจะขอจากฐานข้อมูลทะเบียนเรียนแยกต่างหาก)
- **ข้อมูลส่วนบุคคลที่อ่อนไหว** — เลขบัตรประจำตัวประชาชน, เงินเดือน, ข้อมูลสุขภาพ
- **ผลการประเมินโดยผู้บังคับบัญชา** และ **รายชื่อผู้ทรงคุณวุฒิ** — เป็นกระบวนการภายใน
