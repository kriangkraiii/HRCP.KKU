# นโยบายความมั่นคงปลอดภัยสารสนเทศ (Information Security Policy)
**ระบบ HRCP.KKU — ระบบจัดการข้อมูลบุคลากรและผลงานทางวิชาการ**  
**วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น**  
**มาตรฐานอ้างอิง:** ISO/IEC 27001:2022 (Control 5.1)

---

## 1. วัตถุประสงค์ (Purpose)
นโยบายนี้จัดทำขึ้นเพื่อกำหนดกรอบการดำเนินงานในการรักษาความมั่นคงปลอดภัยสารสนเทศของระบบ HRCP.KKU เพื่อให้มั่นใจว่า:
- **Confidentiality (การรักษาความลับ):** ข้อมูลส่วนบุคคล ข้อมูลผลงาน และข้อมูลทางวิชาการได้รับการปกป้องจากการเข้าถึงโดยไม่ได้รับอนุญาต
- **Integrity (ความถูกต้องครบถ้วน):** ข้อมูลได้รับการคุ้มครองจากการแก้ไข ดัดแปลง หรือทำลายโดยมิชอบ
- **Availability (ความพร้อมใช้งาน):** ระบบและข้อมูลพร้อมให้บริการแก่ผู้ใช้งานที่ได้รับอนุญาตตามข้อตกลงระดับการให้บริการ

---

## 2. ขอบเขตการบังคับใช้ (Scope)
นโยบายนี้ครอบคลุม:
1. ระบบแอปพลิเคชัน HRCP.KKU (Spring Boot Web Application)
2. ฐานข้อมูล PostgreSQL และพื้นที่จัดเก็บไฟล์แนบ (Local/Cloud Storage)
3. ผู้ใช้งานทุกคน (ผู้บริหาร, เจ้าหน้าที่ HR, คณาจารย์, ผู้ดูแลระบบ, ผู้พัฒนา)
4. อุปกรณ์ เครือข่าย และสภาพแวดล้อมที่ใช้ในการประมวลผลระบบ

---

## 3. โครงสร้างและการจัดองค์กรความมั่นคงปลอดภัย (Roles & Responsibilities)
- **คณะกรรมการความมั่นคงปลอดภัย / ผู้บริหารเทคโนโลยีสารสนเทศ:** อนุมัตินโยบายและจัดสรรทรัพยากร
- **ผู้ดูแลระบบ (System Administrator):** ควบคุมการเข้าถึง ดูแลการสำรองข้อมูล และตรวจสอบ Audit Logs
- **ทีมผู้พัฒนาระบบ (Development Team):** พัฒนาระบบตามหลัก Secure Coding และแก้ไขช่องโหว่ตามรอบเวลา
- **ผู้ใช้งานทั่วไป (End Users):** ปฏิบัติตามนโยบายความปลอดภัย ไม่เปิดเผยรหัสผ่าน และรายงานเหตุการณ์ผิดปกติ

---

## 4. มาตรการความมั่นคงปลอดภัยหลัก (Key Security Principles)
1. **Defense-in-Depth:** ป้องกันหลายชั้น (Rate Limiting -> Brute-Force Lock -> Access Control -> MFA -> Audit Log)
2. **Least Privilege & Role-Based Access Control:** ให้สิทธิ์เท่าที่จำเป็นตามบทบาทหน้าที่
3. **Cryptography Standard:** เข้ารหัสรหัสผ่านด้วย BCrypt, สื่อสารผ่าน HTTPS/TLS, แฮช OTP ด้วย SHA-256
4. **Log Retention & Accountability:** บันทึกประวัติการใช้งานและเหตุการณ์สำคัญ ไม่น้อยกว่า 90 วัน ตาม พ.ร.บ.ว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์ พ.ศ. 2560
5. **Personal Data Protection:** ปฏิบัติตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

---

## 5. การทบทวนและการปรับปรุงนโยบาย (Review Cycle)
นโยบายนี้ต้องได้รับการทบทวนอย่างน้อยปีละ 1 ครั้ง หรือเมื่อมีการเปลี่ยนแปลงโครงสร้างระบบหรือข้อกำหนดทางกฎหมายที่มีนัยสำคัญ
