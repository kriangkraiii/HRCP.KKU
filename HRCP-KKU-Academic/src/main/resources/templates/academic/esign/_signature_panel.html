รอเจ้าหน้าที่ตรวจเอกสาร
เจ้าหน้าที่จะตรวจเอกสารและไฟล์แนบ แล้วส่งให้ผู้บริหารลงนามตามลำดับ กรุณาตรวจเอกสารและไฟล์แนบ แล้วกดเริ่มเวียนลงนาม
พักการเวียนลงนาม — รอผู้ยื่นแก้ไขเอกสารที่ส่งกลับและลงนามใหม่ก่อน
ตรวจสอบแล้ว — ลงนามในตำแหน่ง ตรวจสอบแล้ว — ส่งเวียนลงนามต่อ

เลือกผู้ลงนามในตำแหน่งที่เหลือ

ผู้ตรวจสอบเอกสารเป็นผู้ลงนามในตำแหน่งนี้เอง กดยืนยันแล้วระบบพาไปหน้าลงนามด้วย Digital ID

ฉัน
ปล่อยว่างไว้เพื่อใช้กำหนดเวลาเดิม
รหัสตรวจสอบเอกสาร: CODE กำหนดลงนามภายใน: เลยกำหนดที่ตั้งเตือนไว้ (ยังลงนามได้) เลยกำหนด
ส่งกลับให้แก้ไขและลงนามใหม่

ระบบจะยกเลิกการเวียนลงนามรอบนี้ ปลดล็อกเอกสาร และแจ้งเหตุผลให้ผู้ยื่นทางอีเมลและในระบบ

ขยายกำหนดเวลาลงนาม
ระบบจะอัปเดตกำหนดเวลาและแจ้งเตือนผู้ลงนามในลำดับปัจจุบัน
ทำได้จนกว่าจะส่งคำร้อง
รอบเวียนลงนามก่อนหน้าปิดแล้วเนื่องจากเลยกำหนด
ลายเซ็นที่ลงไว้แล้ว 0 / 0 ยังใช้ได้ กรุณาตั้งกำหนดใหม่เพื่อเวียนต่อ หรือเริ่มรอบใหม่จากฟอร์มด้านล่าง
เปิดการเวียนลงนามอีกครั้ง
ระบบจะแจ้งผู้ลงนามลำดับถัดไป
ท่านไม่ต้องลงนามในเอกสารฉบับนี้

กรอกข้อมูลให้ครบแล้วกดบันทึก เมื่อท่านส่งคำร้อง เจ้าหน้าที่จะส่งเวียนให้ ตำแหน่ง และ ลงนาม

รอผู้ยื่นแก้ไขและลงนามใหม่ — ยังเวียนลงนามไม่ได้จนกว่าผู้ยื่นจะลงนามเอกสารที่ส่งกลับ
ลงนามเอกสารฉบับนี้

ท่านลงนามก่อน ส่วนผู้ลงนามคนอื่น เจ้าหน้าที่จะส่งให้ลงนามต่อหลังท่านยื่นคำร้อง

เอกสารฉบับนี้ท่านลงนามคนเดียว

กรุณาตรวจสอบเอกสาร แล้วเลือกผู้ลงนามแต่ละตำแหน่ง
