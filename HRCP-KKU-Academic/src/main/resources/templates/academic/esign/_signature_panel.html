รอเจ้าหน้าที่ตรวจสอบก่อนเวียนลงนาม
เจ้าหน้าที่/นักทรัพยากรบุคคลจะตรวจความถูกต้องของเอกสารและไฟล์แนบก่อน แล้วจึงเริ่มเวียนลงนามไปยังผู้บริหารตามลำดับ ผู้ลงนามถูกเลือกไว้แล้ว เมื่อตรวจเอกสารและไฟล์แนบเรียบร้อย กด “ตรวจสอบแล้ว — เริ่มเวียนลงนาม” เพื่อส่งต่อ
ตรวจสอบแล้ว — ส่งเวียนลงนามต่อ

เมื่อตรวจสอบความถูกต้องของเอกสารและไฟล์แนบแล้ว เลือกผู้ลงนามในตำแหน่งที่เหลือ ระบบจะส่งให้ลงนามตามลำดับขั้นตอน

ปล่อยว่างไว้เพื่อใช้กำหนดเวลาเดิม
รหัสตรวจสอบเอกสาร: CODE กำหนดลงนามภายใน: เลยกำหนดที่ตั้งเตือนไว้ (ยังลงนามได้) เลยกำหนด
ส่งกลับให้แก้ไขและลงนามใหม่

ระบบจะยกเลิกการเวียนลงนามรอบปัจจุบัน ปลดล็อกเอกสารให้แก้ไขได้ และส่งการแจ้งเตือน (Email + In-App) ไปยังผู้ยื่นคำร้องพร้อมเหตุผล

ขยายกำหนดเวลาลงนาม
ระบบจะอัปเดตกำหนดเวลาและแจ้งเตือนผู้ลงนามในลำดับปัจจุบัน
รอบเวียนลงนามก่อนหน้าถูกปิดเพราะเลยกำหนด
ลายเซ็นที่ลงไว้แล้ว 0 / 0 ยังอยู่ครบ — ตั้งกำหนดเวลาใหม่เพื่อเวียนต่อจากเดิม หรือเริ่มรอบใหม่จากฟอร์มด้านล่าง
เปิดการเวียนลงนามอีกครั้ง
ระบบจะเปิดรอบเดิมขึ้นมาใหม่ ลายเซ็นที่ลงไว้แล้วยังอยู่ครบ และจะแจ้งเตือนผู้ลงนามลำดับถัดไปให้ทราบ
การลงนามในส่วนของผู้ยื่นคำร้อง

ท่านจะลงนามเฉพาะในส่วนของผู้ขอรับการประเมิน เมื่อท่านลงนามและกดยื่นคำร้องในระบบแล้ว เจ้าหน้าที่/นักทรัพยากรบุคคลจะเข้าตรวจสอบความถูกต้องของเอกสาร และจัดการส่งเวียนลงนามไปยังผู้บริหาร (หัวหน้าสาขาวิชา/คณบดี) ตามลำดับขั้นตอน

ระบบตรวจสอบก่อนเวียนลงนาม: กรุณาตรวจสอบความถูกต้องของเอกสาร จากนั้นเลือกผู้ลงนามแต่ละตำแหน่ง ระบบจะส่งให้ลงนามตามลำดับขั้นตอน
