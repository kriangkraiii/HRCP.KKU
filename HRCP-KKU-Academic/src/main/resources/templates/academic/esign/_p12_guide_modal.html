คู่มือการขอรับไฟล์ Digital ID (.p12) และรหัสผ่าน มหาวิทยาลัยขอนแก่น Digital ID (.p12) ของหน่วยงานท่าน (ไม่บังคับ)
ไม่บังคับ
หากท่านไม่มี Digital ID ท่านลงนามได้โดยยืนยันรหัสที่ระบบส่งไปทางอีเมล และวิทยาลัยฯ จะรับรองลายมือชื่อในไฟล์ พร้อมระบุชื่อและอีเมลของท่าน
1
ขอใบรับรองจากหน่วยงานของท่าน
หากต้องการลงนามด้วยใบรับรองของท่านเอง ให้ขอใบรับรองดิจิทัลส่วนบุคคลจากฝ่ายเทคโนโลยีสารสนเทศ หรือฝ่ายบุคคลของหน่วยงานต้นสังกัด หรือจากผู้ให้บริการออกใบรับรองที่ได้รับอนุญาต (ดูรายชื่อได้ที่สำนักงานพัฒนาธุรกรรมทางอิเล็กทรอนิกส์ ETDA)
2
ไฟล์และรหัสผ่านที่ใช้ได้
  • ไฟล์ .p12 หรือ .pfx ที่มีกุญแจส่วนตัว และมีชื่อของท่านในใบรับรอง
  • ใบรับรองที่ติดตั้งไว้ใน Windows หรือ macOS Keychain ใช้ได้ ถ้าส่งออก (export) เป็น .pfx/.p12 พร้อมกุญแจส่วนตัว
  • รหัสผ่าน คือรหัสของไฟล์ที่ตั้งตอนดาวน์โหลดหรือที่หน่วยงานแจ้ง ไม่ใช่รหัสผ่านอีเมล
ใช้ไม่ได้: ไฟล์ .cer / .crt / .pem / .p7b ที่มีแต่ใบรับรอง (ไม่มีกุญแจส่วนตัว), ใบรับรองใน USB token หรือ smart card และการลงนามผ่านระบบคลาวด์ของผู้ให้บริการ — กรณีเหล่านี้ กรุณาลงนามด้วยการยืนยันทางอีเมล
3
ติดตั้งในระบบ
  1. ไปที่เมนู ลายเซ็นของฉัน เลือกไฟล์และกรอกรหัสผ่านของไฟล์
  2. กด ตรวจสอบความถูกต้อง แล้ว ติดตั้งและบันทึกใบรับรอง
  3. ระบบเข้ารหัสไฟล์ก่อนเก็บ ไม่เก็บรหัสผ่าน และใช้เฉพาะตอนท่านกดลงนาม ท่านลบออกได้ทุกเมื่อ
วัตถุประสงค์ของไฟล์ Digital ID (.p12)
ใบรับรองดิจิทัลส่วนบุคคล (.p12 / .pfx) ออกโดยมหาวิทยาลัยขอนแก่น ใช้รับรองตัวตนผู้ลงนามตาม พ.ร.บ.ว่าด้วยธุรกรรมทางอิเล็กทรอนิกส์ พ.ศ. 2544 มาตรา 26 เอกสารที่ลงนามแล้วตรวจสอบความถูกต้องได้ด้วยโปรแกรม Adobe Acrobat Reader
1
ดาวน์โหลดไฟล์ .p12
  1. เข้าสู่ระบบพอร์ทัลบริการบุคลากร มข. (iKKU) ที่ https://i.kku.ac.th
  2. เข้าสู่ระบบด้วยบัญชีผู้ใช้ @kku.ac.th ของท่าน
  3. เลือกบริการ "Digital ID" หรือ "ลายมือชื่อดิจิทัล" > "ขอรับใบรับรองดิจิทัลส่วนบุคคล (.p12)"
  4. กดดาวน์โหลดไฟล์ .p12 (หรือ .pfx) มาเก็บไว้ในเครื่องคอมพิวเตอร์ของท่าน
2
รหัสผ่านของไฟล์ .p12
รหัสผ่านนี้ไม่ใช่รหัสผ่านอีเมลหรือ KKU SSO
  • รหัสผ่านที่ท่านกำหนดเองตอนดาวน์โหลดไฟล์จาก i.kku.ac.th
  • หรือรหัสเริ่มต้นที่มหาวิทยาลัยแจ้งทาง KKU Mail หรือ SMS
หากจำรหัสผ่านไม่ได้ กรุณาดาวน์โหลดไฟล์ .p12 ใหม่จาก i.kku.ac.th พร้อมตั้งรหัสผ่านใหม่
3
ติดตั้งในระบบ
  1. ไปที่เมนู ลายเซ็นของฉัน
  2. เลือกไฟล์ .p12 และกรอกรหัสผ่านของไฟล์
  3. กด ตรวจสอบความถูกต้อง ระบบจะแสดงชื่อเจ้าของใบรับรองและวันหมดอายุ
  4. กด ติดตั้งและบันทึกใบรับรอง ระบบเก็บเฉพาะไฟล์ .p12 (เข้ารหัส) ไม่เก็บรหัสผ่าน — กรอกรหัสผ่านทุกครั้งที่ลงนาม ลายเซ็นดิจิทัลของท่านจะถูกลงในเอกสารทันที
คำถามที่พบบ่อย
  • เปลี่ยนไฟล์หรือรหัสผ่าน: ติดตั้งไฟล์ .p12 ใหม่พร้อมรหัสผ่านที่หน้าลายเซ็นของฉัน ใบเดิมจะถูกปิดใช้อัตโนมัติ
  • อายุการใช้งาน: ใช้ได้จนใบรับรองหมดอายุ ระบบจะแจ้งเตือนเมื่อใกล้หมดอายุ
  • ความปลอดภัย: ไฟล์ .p12 ถูกเข้ารหัสและเก็บในพื้นที่ที่เปิดผ่านเว็บไม่ได้ ระบบไม่เก็บรหัสผ่าน และบันทึกทุกครั้งที่มีการใช้ใบรับรองของท่าน
