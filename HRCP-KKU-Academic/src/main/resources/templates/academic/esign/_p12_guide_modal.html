คู่มือการขอรับไฟล์ Digital ID (.p12) และรหัสผ่าน มหาวิทยาลัยขอนแก่น
ทำไมต้องใช้ไฟล์ Digital ID (.p12)?
ไฟล์ใบรับรองดิจิทัลส่วนบุคคล (.p12 / .pfx) ออกโดยมหาวิทยาลัยขอนแก่น (ODT KKU) เพื่อใช้รับรองตัวตนผู้ลงนามตาม พ.ร.บ.ว่าด้วยธุรกรรมทางอิเล็กทรอนิกส์ พ.ศ. 2544 มาตรา 26 (ลายมือชื่อดิจิทัลที่มีผลทางกฎหมายระดับสูง) ช่วยป้องกันการปลอมแปลงและตรวจสอบความถูกต้องของเอกสารได้ 100% ผ่านโปรแกรม Adobe Acrobat Reader
1
วิธีขอรับ/ดาวน์โหลดไฟล์ .p12 จาก มข.

บุคลากร มข. ทุกท่านสามารถดาวน์โหลดใบรับรอง Digital ID ประจำตัวได้ง่ายๆ ผ่านพอร์ทัล iKKU:

  1. เข้าสู่ระบบพอร์ทัลบริการบุคลากร มข. (iKKU) ที่ https://i.kku.ac.th
  2. เข้าสู่ระบบด้วยบัญชีผู้ใช้ @kku.ac.th ของท่าน
  3. เลือกบริการ "Digital ID" หรือ "ลายมือชื่อดิจิทัล" > "ขอรับใบรับรองดิจิทัลส่วนบุคคล (.p12)"
  4. กดดาวน์โหลดไฟล์ .p12 (หรือ .pfx) มาเก็บไว้ในเครื่องคอมพิวเตอร์ของท่าน
2
Digital ID Password (รหัสผ่านของไฟล์ .p12) เอามาจากไหน?
ข้อสำคัญ: Digital ID Password นี้ ไม่ใช่ รหัสผ่านอีเมล หรือรหัสผ่าน SSO มข. ทั่วไป!

Digital ID Password ที่ใช้เปิดไฟล์ .p12 คือ:

  • รหัสผ่านที่ท่านกำหนดขึ้นเอง ตอนกดขอรับ/ดาวน์โหลดไฟล์ .p12 จากระบบ i.kku.ac.th เพื่อความปลอดภัยของกุญแจส่วนตัว
  • หรือในบางกรณี ระบบ มข. อาจสร้างรหัสเริ่มต้นและแจ้งให้ท่านทราบทาง KKU Mail หรือ SMS ขณะดาวน์โหลดไฟล์
*หากจำรหัสผ่านไม่ได้ ท่านสามารถเข้าสู่ระบบ https://i.kku.ac.th เพื่อกดดาวน์โหลดไฟล์ .p12 ใหม่พร้อมตั้ง Digital ID Password ใหม่ได้ตลอดเวลา
3
วิธีนำมาติดตั้งในระบบ (ใส่ครั้งเดียว พร้อมตรวจสอบความถูกต้อง)
  1. ไปที่เมนู "ลายเซ็นของฉัน" เลื่อนลงมาที่หัวข้อ "ใบรับรองดิจิทัล Digital ID (.p12)"
  2. คลิกปุ่ม "เลือกไฟล์" แล้วเลือกไฟล์ .p12 ที่ดาวน์โหลดมาจาก i.kku.ac.th
  3. กรอก Digital ID Password ในช่องข้อความ
  4. กดปุ่ม ตรวจสอบความถูกต้อง — เพื่อให้ระบบทดสอบปลดล็อกไฟล์ทันที ป้องกันการใส่รหัสผิดหรือเลือกไฟล์ผิด หากรหัสถูกต้อง ระบบจะแสดงชื่อเจ้าของใบรับรองและวันหมดอายุให้ท่านทราบ
  5. กดปุ่ม "ติดตั้งและบันทึกใบรับรอง" — ระบบจะบันทึกและเข้ารหัส Digital ID Password ด้วยมาตรฐาน AES-256 ให้อัตโนมัติครั้งเดียว เพื่อให้ท่านสามารถลงนามในเอกสารทุกฉบับได้ในคลิกเดียว (One-Click Sign) ทันที!
คำถามที่พบบ่อย (FAQ):
  • หากต้องการเปลี่ยนรหัสผ่านหรืออัปเดตไฟล์ในภายหลัง? สามารถกดปุ่ม "เปลี่ยนไฟล์ .p12" ที่การ์ดใบรับรองเพื่ออัปเดตไฟล์ฉบับใหม่ได้ตลอดเวลา
  • ติดตั้งครั้งเดียว ใช้ได้ตลอดหรือไม่? ใช้ได้ตลอดอายุของใบรับรอง เมื่อใกล้หมดอายุระบบจะแจ้งเตือนให้ท่านอัปโหลดไฟล์ใหม่แทนที่
  • ข้อมูลความปลอดภัย: ไฟล์กุญแจและรหัสผ่านถูกจัดเก็บในระบบที่เข้ารหัสอย่างเข้มงวด เข้าถึงได้เฉพาะขั้นตอนการประทับตราดิจิทัลของท่านเท่านั้น
