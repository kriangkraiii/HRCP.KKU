# แผนงาน: ย้ายปุ่มเปลี่ยนภาษาไปไว้ข้างค้นหาด่วนทางขวา (Move Language Switcher to Topbar)

> เอกสารแผนงานตามคำสั่ง `/plan` สำหรับการปรับโครงสร้าง UI และตำแหน่งปุ่มเปลี่ยนภาษา

---

## 1. วัตถุประสงค์ (Objective)
ย้ายส่วนควบคุมการเปลี่ยนภาษา (`.lang-dropdown`) จากตำแหน่งเดิมที่อยู่ด้านล่างของแถบเมนูด้านข้าง (Sidebar) ขึ้นมาอยู่ที่แถบเครื่องมือด้านบน (Topbar) โดยจัดวางให้อยู่ทางด้านขวาถัดจากช่องค้นหาด่วน (`.global-search-container`) เพื่อให้สอดคล้องกับการใช้งานทั่วไป เป็นจุดที่ผู้ใช้สังเกตเห็นได้ง่าย และเพิ่มพื้นที่ให้กับเมนูในแถบด้านข้าง

---

## 2. การวิเคราะห์โครงสร้างเดิมและปัญหาที่พบ (Current Architecture & Analysis)

### 2.1 โครงสร้างเดิม
- **ตำแหน่งใน DOM:** อยู่ภายใน `<aside class="academic-sidebar">` หลังแท็ก `</nav>` (บรรทัดที่ 183-192 ของ `base_academic.html`)
- **การจัดสไตล์ CSS (`style.css`):**
  - ปุ่มเดิมถูกออกแบบสำหรับพื้นหลังสีน้ำเงินเข้มของ Sidebar (ข้อความสีขาว `rgba(255, 255, 255, 0.8)`)
  - เมนู Dropdown มีการกำหนด `bottom: 100%` และ `background: #2a2a2a` เพื่อให้เด้งขึ้นด้านบน (Drop-up) เนื่องจากอยู่ด้านล่างสุดของหน้าจอ

### 2.2 สิ่งที่ต้องปรับปรุงเมื่อย้ายมา Topbar
1. **ทิศทางของ Dropdown:** ต้องเปลี่ยนจากเด้งขึ้นด้านบน (`bottom: 100%`) เป็นเด้งลงด้านล่าง (`top: calc(100% + 6px)`)
2. **ธีมสีและคอนทราสต์:** ปุ่มใน Topbar ต้องเข้ากับพื้นหลังสีขาว/สว่างใน Light Mode และปรับตาม Dark Mode ได้อย่างกลมกลืน (ใช้ CSS Variables)
3. **การจัดวาง (Layout):** ต้องอยู่ติดกับกล่องค้นหาด่วน (`.global-search-container`) ทางด้านขวา และอยู่ก่อนปุ่มคู่มือการใช้งาน (`topbar-icon-btn`)
4. **ความสมบูรณ์ของระบบแปลภาษา:** รักษา `<div id="google_translate_element"></div>` และ Script การทำงานของ Google Translate ให้ทำงานได้สมบูรณ์ 100%

## 3. แผนการดำเนินงาน (Task Breakdown)

### ส่วนที่ 1: การปรับแต่งเทมเพลต (`base_academic.html`)
- ย้ายบล็อก `<div class="lang-dropdown">...</div>` จาก Sidebar ไปไว้ใน Topbar ถัดจาก `.global-search-container`
- คงตำแหน่ง `<div id="google_translate_element"></div>` ไว้ใน DOM เพื่อให้ Google Translate Library โหลดและ Initialize ได้ตามปกติ
- รักษา ID เดิม (`langDropdownBtn`, `langDropdownIcon`, `langCurrentLabel`, `langDropdownMenu`) เพื่อให้ Script การเปลี่ยนภาษาเดิมทำงานได้ต่อเนื่องโดยไม่ต้องแก้ Logic การแปล

### ส่วนที่ 2: การปรับสไตล์ CSS สำหรับ Topbar (`base_academic.html` / `style.css`)
- เพิ่มคลาสเฉพาะสำหรับ Topbar เช่น `.topbar-lang-dropdown`, `.topbar-lang-btn`, `.topbar-lang-menu`
- ปรับรูปแบบปุ่มเป็นทรง Pill/Capsule หรือ Icon-button ที่ดูพรีเมียม สุภาพ สะอาดตา
- กำหนดตำแหน่งของ Dropdown เมนู:
  - `top: calc(100% + 6px);`
  - `right: 0; left: auto; bottom: auto;`
  - พื้นหลังรองรับธีมสว่างและมืด (`var(--bg-card)`, `var(--border-color)`)
- จัดการ Responsive ในหน้าจอมือถือ (ความกว้างหน้าจอน้อยกว่า 768px) ไม่ให้เบียดหรือตกบรรทัด

### ส่วนที่ 3: การตรวจสอบและทดสอบ (Verification & Testing)
- ตรวจสอบการคลิกเปิด/ปิดเมนู Dropdown
- ตรวจสอบการสลับภาษา TH และ EN ว่าเนื้อหาถูกแปล และ Cookie บันทึกถูกต้อง
- ตรวจสอบการแสดงผลทั้งใน Light Mode และ Dark Mode
- รันชุดการทดสอบระบบที่มีอยู่เพื่อยืนยันว่าไม่มีผลกระทบต่อส่วนอื่นๆ
