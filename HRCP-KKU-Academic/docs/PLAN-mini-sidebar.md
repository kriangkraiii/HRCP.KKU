# แผนงาน: ปรับปรุงแถบเมนูด้านข้างเมื่อกดซ่อนให้เป็นแบบย่อไอคอน (Mini-Sidebar / Icon Rail)

> เอกสารแผนงานตามคำสั่ง `/plan` สำหรับการปรับโครงสร้าง UI และ CSS ของ Sidebar ในโหมด Desktop Collapse

---

## 1. วัตถุประสงค์ (Objective)

ปรับเปลี่ยนพฤติกรรมของแถบเมนูด้านข้าง (Sidebar) บนหน้าจอเดสก์ท็อป เมื่อผู้ใช้กดปุ่มซ่อนเมนู (Sidebar Toggle / Hide) จากเดิมที่แถบเมนูจะเลื่อนออกนอกหน้าจอไปทั้งหมด (`transform: translateX(-100%);` เหลือพื้นที่ว่าง 0px) ให้เปลี่ยนเป็นการย่อขนาดเป็น **Mini-Sidebar (Icon Rail)** ความกว้างประมาณ 70px ตามภาพตัวอย่างที่ผู้ใช้ระบุ เพื่อให้ผู้ใช้ยังคงมองเห็นไอคอนของเมนูหลัก สามารถคลิกเข้าถึงฟังก์ชันต่างๆ ได้อย่างสะดวกรวดเร็ว และเพิ่มพื้นที่ทำงานให้กับส่วนเนื้อหาหลัก (Main Content) ได้พร้อมกัน

---

## 2. การวิเคราะห์เปรียบเทียบกับภาพอ้างอิง (Visual & Functional Analysis)

จากภาพอ้างอิงที่ผู้ใช้แนบมา มีองค์ประกอบสำคัญที่ต้องนำมาปรับใช้ดังนี้:

1. **ขนาดความกว้างแบบ Rail:** แถบด้านข้างลดความกว้างจาก 260px เหลือประมาณ 70px (ใช้ตัวแปร `--sidebar-collapsed: 70px;` ที่มีอยู่แล้ว)
2. **ส่วนหัวและตราสัญลักษณ์ (Brand / Logo):**
   - ซ่อนข้อความชื่อระบบและชื่อหน่วยงาน (`h6`, `small`)
   - แสดงเฉพาะไอคอนหรือโลโก้ขนาดกะทัดรัด จัดกึ่งกลางแนวนอนอย่างสมดุล
3. **รายการเมนูนำทาง (Navigation Items):**
   - ซ่อนข้อความชื่อเมนู (`.sidebar-link-text`) และลูกศร Dropdown
   - จัดไอคอนของแต่ละเมนูให้อยู่ตรงกลางของแถบ
   - รูปแบบปุ่มเป็นสี่เหลี่ยมขอบมน (Rounded Box) ขนาดพอเหมาะ (เช่น 44px x 44px)
   - สถานะ Active และ Hover มีพื้นหลังไฮไลต์ชัดเจนสวยงาม
4. **ป้ายข้อความลอยเมื่อชี้เมาส์ (Floating Tooltips on Hover):**
   - เมื่อผู้ใช้นำเมาส์ไปชี้ (Hover) ที่ไอคอนเมนู จะมีกล่องข้อความสีเข้มลอยออกมาทางขวามือ (เช่น "Settings" หรือชื่อเมนูภาษาไทย) เพื่อบอกชื่อเมนูโดยไม่ต้องกดเปิด Sidebar
5. **หัวข้อหมวดหมู่ (Section Titles):**
   - ซ่อนข้อความหัวข้อยาว หรือเปลี่ยนเป็นเส้นคั่นบางๆ / ป้ายสั้นจัดกึ่งกลางเพื่อแยกหมวด
6. **ป้ายแจ้งเตือน (Notification & Pending Badges):**
   - ปรับตำแหน่งตัวเลขแจ้งเตือนให้เป็น Badge จุดเล็ก (Mini Dot Badge) อยู่ที่มุมขวาบนของไอคอนเมนู
7. **ส่วนล่างและข้อมูลผู้ใช้ (Footer / User Profile):**
   - ซ่อนข้อความชื่อ-นามสกุลและบทบาทของผู้ใช้
   - แสดงเฉพาะรูปภาพ Avatar ทรงกลมจัดกึ่งกลาง
   - ปุ่มออกจากระบบ (Logout) ปรับเป็นปุ่มไอคอนจัดกึ่งกลาง พร้อม Tooltip กำกับ
8. **การเลื่อนไหลของหน้าจอ (Smooth Transitions):**
   - ปรับความกว้างของ Sidebar และ Margin ของ Main Content ด้วย Transition 0.25 - 0.3 วินาที เพื่อให้ยุบ/ขยายอย่างนุ่มนวล ไม่กระตุก
9. **ความเข้ากันได้กับอุปกรณ์มือถือ (Mobile Responsiveness):**
   - บนหน้าจอขนาดเล็ก (< 992px) ยังคงใช้พฤติกรรม Drawer สไลด์เข้า-ออกแบบเต็ม เพื่อไม่ให้บดบังพื้นที่ของจอมือถือ

## 3. แผนการดำเนินงาน (Task Breakdown)

### ส่วนที่ 1: การปรับแต่งสไตล์ CSS (`style.css` และ `dark-theme.css`)
- ปรับปรุง CSS Rule ของ `html.sidebar-collapsed .sidebar` และ `body.sidebar-collapsed .sidebar`:
  - เปลี่ยนจาก `transform: translateX(-100%);` เป็น `width: var(--sidebar-collapsed, 70px);` และ `transform: none;`
  - เพิ่ม `transition: width var(--duration-normal) var(--ease-out-quart), transform var(--duration-normal);`
- ปรับแต่ง `html.sidebar-collapsed .main-content`:
  - เปลี่ยนจาก `margin-left: 0 !important;` เป็น `margin-left: var(--sidebar-collapsed, 70px) !important;`
- ปรับตำแหน่งปุ่มลอยย้อนกลับ:
  - `html.sidebar-collapsed .floating-doc-btn-back` ให้มี `left: calc(var(--sidebar-collapsed, 70px) + 24px) !important;`
- ปรับแต่งองค์ประกอบภายใน Sidebar เมื่ออยู่ในโหมด `sidebar-collapsed`:
  - **ส่วน Brand:** ซ่อนตัวหนังสือ ปรับขนาด Padding ให้เหลือเฉพาะไอคอนตรงกลาง
  - **ส่วน Section Title:** แปลงเป็นเส้นคั่นหรือซ่อนตัวหนังสือยาว
  - **ส่วน Link/Icon:** จัดกึ่งกลาง ซ่อนข้อความตัวหนังสือ กำหนดขนาดกรอบไอคอน 42px x 42px
  - **ส่วน Tooltip:** สร้าง CSS Floating Tooltip ผ่านคุณสมบัติ `data-title` หรือ `::after` / Tooltip Container ที่แสดงผลทางขวาเมื่อ Hover
  - **ส่วน Footer & Profile:** จัด Avatar กึ่งกลาง ซ่อนชื่อ และปรับปุ่ม Logout เป็นไอคอนกึ่งกลาง
- ปรับปรุง Dark Theme ใน `dark-theme.css` ให้รองรับสีและเงาของ Tooltip และ Active Box อย่างกลมกลืน

### ส่วนที่ 2: การปรับปรุงเทมเพลตและสคริปต์ (`base_academic.html`)
- ตรวจสอบและเพิ่ม `data-title` หรือ `title` ให้กับทุกลิงก์เมนูใน Sidebar สำหรับการแสดงผล Tooltip
- ปรับปรุงฟังก์ชัน JavaScript การ Toggle Sidebar ให้รองรับการเปิด-ปิดในโหมด Mini-Sidebar ได้อย่างราบรื่น
- จัดการกรณีเมนู Dropdown ย่อยเมื่ออยู่ในโหมด Mini-Sidebar (คลิกแล้วนำทาง หรือขยาย Flyout ออกมาทางขวา)
- จัดการ Anti-flash script ให้จำสถานะผ่าน `localStorage.getItem('sidebar_collapsed')` ได้อย่างถูกต้อง

### ส่วนที่ 3: การตรวจสอบและทดสอบ (Verification & Testing)
- ทดสอบการกดปุ่ม Toggle ในหน้าจอเดสก์ท็อป ทั้งการยุบ (Collapse) และขยาย (Expand)
- ตรวจสอบการลอยของ Tooltip เมื่อชี้เมาส์ที่แต่ละเมนู
- ทดสอบการคลิกเข้าเมนูต่างๆ ขณะอยู่ในโหมด Mini-Sidebar ว่าสามารถนำทางได้ถูกต้อง
- ตรวจสอบการแสดงผลทั้งใน Light Theme และ Dark Theme
- ตรวจสอบความถูกต้องบนหน้าจอมือถือและแท็บเล็ต
- รันชุด Automated Tests ของระบบเพื่อให้มั่นใจว่าไม่มีผลกระทบต่อส่วนอื่นๆ

## 5. คำถามเชิงกลยุทธ์และข้อตกลงในการออกแบบ (Socratic Gate & Design Choices)

ก่อนเริ่มลงมือเขียนโค้ด มีประเด็นทางเทคนิคและประสบการณ์ผู้ใช้ที่นำเสนอเพื่อความชัดเจน:

1. **ป้ายแจ้งเตือน (Notification Badges) ในโหมด Mini-Sidebar:**
   - ทางเลือก A (แนะนำ): แสดงเป็นจุดวงกลมสีแดงเล็กๆ (Red Dot) ที่มุมขวาบนของไอคอนเมนูแจ้งเตือน และแสดงตัวเลขจำนวนเต็มเมื่อ Hover ใน Tooltip
   - ทางเลือก B: ซ่อนป้ายไว้ แล้วแสดงตัวเลขเฉพาะใน Tooltip เท่านั้น
2. **เมนูย่อยที่มีรายการข้างใน (Dropdown Menus):**
   - ทางเลือก A (แนะนำ): เมื่ออยู่ในโหมด Mini-Sidebar และผู้ใช้ชี้หรือคลิกเมนูที่มีเมนูย่อย ให้แสดงเป็น Flyout Submenu ลอยออกมาทางขวาถัดจาก Sidebar
   - ทางเลือก B: เมื่อกดเมนูที่มีเมนูย่อย ให้ขยาย Sidebar กลับเป็นขนาดเต็มก่อน
3. **ปุ่มเปิด/ปิด (Toggle Button) ภายใน Sidebar:**
   - ในภาพตัวอย่างมีปุ่ม Toggle ขนาดเล็กอยู่ด้านบนของแถบไอคอนด้วย ต้องการให้คงปุ่ม Toggle ไว้ที่ Topbar เหมือนเดิม หรือเพิ่มปุ่ม Toggle เล็กๆ ไว้ในตัว Mini-Sidebar ด้วย?
