| ขั้นตอน | ผู้กระทำ | การกระทำ |
|---------|---------|---------|
| 1 | ผู้ดูแลระบบ | คลิกเมนู "คำร้องประเมินผลการสอน" (GET `/admin/academic/requests`) |

```mermaid
    S->>DB: ดึงรายชื่อบุคลากร/กรรมการ
    S-->>A: แสดงฟอร์มกรอกเอกสาร (พร้อม auto-fill)

    A->>S: POST /admin/academic/request/{id}/document/{type} (formData)
    S->>S: ประมวลผล formData (checkbox, คะแนน, เลขไทย)

    alt type == 4 (3 สำเนา)
        S->>DG: generateDocument4Copies(id, jsonData, committeeMembers)
        DG-->>S: [filePath1, filePath2, filePath3]
        S->>DB: saveDocument × 3 สำเนา
    else type อื่น
        S->>DG: generateDocument(id, type, jsonData)
        DG-->>S: filePath
        S->>DB: saveDocument
    end

    S->>DB: บันทึก admin log
    S-->>A: Redirect + "สร้างเอกสารสำเร็จ"
```
