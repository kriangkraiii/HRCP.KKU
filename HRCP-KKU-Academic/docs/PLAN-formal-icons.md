# PLAN: ปรับปรุงชุดสัญลักษณ์ไอคอนให้มีความเป็นทางการและน่าเชื่อถือทั้งระบบ (PLAN-formal-icons.md)

## 1. ปัญหาและเป้าหมาย (Problem Statement & Goals)

### ปัญหาที่พบ
- สัญลักษณ์รูปดาวหยัก/ตรายางหยัก (fa-certificate) ที่ปรากฏในส่วนใบรับรองดิจิทัล Digital ID (.p12) และสถานะรับรองมติ มีลักษณะขอบหยักแหลมคล้ายป้ายลดราคา (Discount Seal / Starburst Sticker) ทำให้ภาพลักษณ์ดูไม่เป็นทางการ ขาดความเป็นมาตรฐานของระบบเอกสารราชการและมหาวิทยาลัย
- สัญลักษณ์อื่นๆ บางจุดมีลักษณะกึ่งของเล่นหรือไม่เป็นทางการ เช่น:
  - fa-star (รูปดาว) ในป้าย "ค่าเริ่มต้น / ลายเซ็นหลัก" ดูเหมือนดาวให้คะแนนรีวิว
  - fa-eraser (ยางลบ) ในปุ่มล้างลายเซ็น ดูเหมือนเครื่องมือวาดรูปเล่น
  - fa-hourglass-start / fa-hourglass-half (นาฬิกาทราย) ในสถานะรอดำเนินการ
  - fa-bolt (สายฟ้า) ในฟังก์ชัน One-Click Sign ดูเหมือนเกมหรือความเร็วที่ไม่เน้นความรัดกุมปลอดภัย

### เป้าหมาย
1. ถอดสัญลักษณ์ fa-certificate (ขอบหยัก) ออกจากทุกจุดในทั้งโปรเจกต์ และเปลี่ยนเป็นสัญลักษณ์ที่ดูน่าเชื่อถือ เป็นทางการ และตรงกับมาตรฐานวิชาชีพ
2. ตรวจสอบและเปลี่ยนสัญลักษณ์ประกอบอื่นๆ ให้มีภาพลักษณ์ที่เป็นทางการ (Formal, Official & Academic Standard)
3. รักษาสไตล์และโครงสร้างคลาส CSS เดิม ไม่ให้กระทบต่อ Layout หรือการทำงานของระบบ

## 2. การวิเคราะห์และเปรียบเทียบชุดสัญลักษณ์ใหม่ (Icon Mapping & Rationales)

### 2.1 สัญลักษณ์หลัก: Digital ID (.p12) และใบรับรองความปลอดภัย
- **เดิม:** `fa-certificate` (ดาวหยัก / ตราประทับขอบหยัก)
- **เปลี่ยนเป็น (ทางเลือกที่แนะนำ):**
  - สำหรับ Digital ID / ข้อมูลประจำตัวดิจิทัล: ใช้ **`fa-id-card`** (บัตรประจำตัวดิจิทัลราชการ/มหาวิทยาลัย)
  - สำหรับสถานะความปลอดภัยและการเข้ารหัสลับ PAdES: ใช้ **`fa-shield-halved`** หรือ **`fa-file-shield`** (ตราโล่ความปลอดภัยอิเล็กทรอนิกส์)
  - สำหรับหัวข้อหน้าต่าง/ปุ่มจัดการใบรับรอง: ใช้ **`fa-id-card`**

### 2.2 สัญลักษณ์สถานะคำร้องใน PositionRequestStatus.java
- **เดิม:** `COLLEGE_APPROVED("รับรองมติคณะกรรมการวิทยาลัยฯ", "fa-certificate", "#1b5e20")`
- **เปลี่ยนเป็น:** `fa-stamp` (ตราประทับรับรองมติอย่างเป็นทางการ) หรือ `fa-file-circle-check` (เอกสารผ่านการรับรองมติสมบูรณ์)

### 2.3 สัญลักษณ์ประกอบอื่นๆ ที่ปรับให้ดูทางการ
1. **ป้าย "ลายเซ็นหลัก / ค่าเริ่มต้น":**
   - เดิม: `fa-star` (รูปดาว)
   - เปลี่ยนเป็น: `fa-circle-check` หรือ `fa-check` (เครื่องหมายตรวจสอบยืนยันทางการ)
2. **ปุ่ม "ล้าง" ในหน้ากระดานวาดลายเซ็น:**
   - เดิม: `fa-eraser` (ยางลบ)
   - เปลี่ยนเป็น: `fa-rotate-left` (ย้อนกลับ/เริ่มวาดใหม่)
3. **สถานะ "รอการติดตั้ง Digital ID":**
   - เดิม: `fa-hourglass-start` (นาฬิกาทราย)
   - เปลี่ยนเป็น: `fa-clock` หรือ `fa-circle-pause` (สัญลักษณ์เวลาทางการ)
4. **ข้อความ "One-Click Sign":**
   - เดิม: `fa-bolt` (สายฟ้า)
   - เปลี่ยนเป็น: `fa-key` หรือ `fa-fingerprint` (กุญแจเข้ารหัส / ยืนยันตัวตน)

## 3. รายการไฟล์ที่จะต้องดำเนินการปรับปรุง (Target Files)

1. **`my_signatures.html`**
   - ปุ่ม "จัดการใบรับรอง .p12": เปลี่ยนจาก `fa-certificate` เป็น `fa-id-card`
   - การ์ดขั้นตอนที่ 1: เปลี่ยนจาก `fa-certificate` เป็น `fa-id-card`
   - หัวข้อ Modal จัดการใบรับรอง: เปลี่ยนจาก `fa-certificate` เป็น `fa-id-card`
   - ป้าย "รอการติดตั้ง Digital ID": เปลี่ยนจาก `fa-hourglass-start` เป็น `fa-clock`
   - ปุ่มล้างลายเส้น: เปลี่ยนจาก `fa-eraser` เป็น `fa-rotate-left`
   - ป้าย "ลายเซ็นหลัก": เปลี่ยนจาก `fa-star` เป็น `fa-circle-check`

2. **`sign.html`**
   - กล่องแจ้งเตือนใบรับรองหมดอายุ: เปลี่ยนจาก `fa-certificate` เป็น `fa-id-card`
   - ส่วนหัว "ลงนามด้วย Digital ID (.p12) มข.": เปลี่ยนจาก `fa-certificate` เป็น `fa-id-card`
   - ป้าย "ค่าเริ่มต้น" บนการ์ดเลือกลายเซ็น: เปลี่ยนจาก `fa-star` เป็น `fa-circle-check`
   - กล่องข้อมูล One-Click Sign: เปลี่ยนจาก `fa-bolt` เป็น `fa-key`

3. **`PositionRequestStatus.java`**
   - ค่า `COLLEGE_APPROVED`: เปลี่ยนไอคอนจาก `"fa-certificate"` เป็น `"fa-file-circle-check"` หรือ `"fa-stamp"`
