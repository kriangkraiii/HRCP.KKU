**ต่อยอดจาก:** `PLAN-signer-picker.md` (ตัวค้นหาชื่อ), `PLAN-external-signer.md` (ผู้ลงนามนอก มข.)

## 1. โจทย์

> *"ประธานกรรมการ และกรรมการอีกสองคนในเฟส 1 คือคนที่มีบัญชีในระบบ เวลาเลือกก็เลือกเหมือนเอกสารที่ 3 เพราะเอกสารที่ 7 ต้องให้เซ็นทั้งสามคน"*

## 3. แนวทางที่เสนอ: เลือกครั้งเดียวที่ฉบับ 3 แล้วส่งต่อทั้งชื่อและบัญชี

กรรมการถูกแต่งตั้งตามคำสั่งในฉบับ 3/4 คนที่ลงนามฉบับ 7–8 ต้องเป็นคนเดียวกับที่ถูกแต่งตั้ง
จึงเลือกที่ฉบับ 3 ที่เดียว (ตัวค้นหาชื่อแบบเดียวกับช่องคณบดี/หัวหน้าสาขา) แล้วส่ง **ชื่อ + `__signer`** ต่อไปฉบับ 4 → 5 → 7 → 8 แบบอ่านอย่างเดียว เหมือนที่ฉบับ 5 รับจากฉบับ 4 ตอนนี้

**ทางที่ไม่เลือก:** เลือกใหม่ที่ฉบับ 7 — เอกสารที่ 7 ระบุกรรมการคนละชุดกับคำสั่งแต่งตั้งได้ และต้องเลือกซ้ำสองที่

## 4. การออกแบบ

### 4.1 ฉบับ 3 — ตัวค้นหาชื่อสำหรับกรรมการ 3 คน
- `admin/doc_fragments/3.html`: เปลี่ยน `committee_{i}_name` เป็น `data-person-picker data-role="COMMITTEE"` (ไม่มีช่องตำแหน่งให้เติม — ตำแหน่งเป็นข้อความคงที่อยู่แล้ว) เอา datalist ออก
- กรรมการคนที่ 2 เป็น "อนุกรรมการ (ภายนอก)" → ใส่ `data-allow-external` **เฉพาะคนที่ 2** ให้เพิ่มคนนอก มข. ทางอีเมลได้ (`ExternalSignerService` มีแล้ว) คนที่ 1 และ 3 (ภายใน) เลือกได้เฉพาะบัญชีที่มีอยู่
- **ไม่ใช่ผู้ลงนามของฉบับ 3** — ต้องแยกแนวคิด "ช่องที่ต้องเลือกจากบัญชี" ออกจาก "ช่องที่ผูกผู้ลงนามของฉบับนี้" ใน `SignatureAnchorRegistry`:
  - เพิ่มตาราง `PERSON_FIELDS` (ช่องที่เป็นตัวค้นหาชื่อแต่ไม่ได้ลงนามในฉบับนี้) — ใช้ตอนตรวจความครบ/ปฏิเสธชื่ออิสระ
  - `SIGNER_NAME_FIELDS` ของฉบับ 3 คงเดิม (4 ตำแหน่ง) — แผงลงนามฉบับ 3 ไม่เปลี่ยน
- กันเลือกคนซ้ำ: กรรมการ 3 คนต้องเป็นคนละบัญชี (เช็กทั้งหน้าเว็บและตอนบันทึก)
- `namesThreeSubCommitteeMembers` (`AcademicRequestService`) นับว่าครบเมื่อมีชื่อ **และ** `__signer` ครบ 3 คน

### 4.2 ส่งต่อรหัสบัญชีไปฉบับถัดไป
- `carriedIntoDoc4` / `carriedIntoDoc5`: ส่ง `committee_{i}_name__signer` ไปพร้อมชื่อ
- `AcademicAdminController` (บล็อก `defaultCommittee1..3`): เพิ่ม `defaultCommittee{i}Signer` จากฉบับ 3
- `DocumentDataAutoFillHelper`: คัดลอก `committee_{i}_name__signer` คู่กับชื่อ

### 4.3 ฉบับ 7 — ลงนามครบ 3 คน
- `SignatureAnchorRegistry` ACADEMIC 7:
  ```
  committee_chair    ประธานคณะกรรมการ   committee_1_name  COMMITTEE  order 1
  committee_member_2 กรรมการ            committee_2_name  COMMITTEE  order 2
  committee_member_3 กรรมการ            committee_3_name  COMMITTEE  order 3
  ```
  ประธานเซ็นก่อน แล้วคนที่ 2 แล้วคนที่ 3 — ระบบเวียนลงนามเปิดให้เซ็นทีละคนเสมอ (`SignatureWorkflowService`: ACTIVE ได้ทีละขั้น)
  ลำดับเท่ากันไม่ได้แปลว่าเซ็นพร้อมกันจริง จึงระบุลำดับตามที่เกิดขึ้นจริง
- `SIGNER_NAME_FIELDS` ACADEMIC 7: `committee_1_name`, `committee_2_name`, `committee_3_name` (ไม่มีช่องตำแหน่ง → `""`)
- `7.html`: ทั้งสามช่องเป็นชื่อที่รับมาแบบอ่านอย่างเดียว + `__signer` ซ่อน (แบบฟอร์มฉบับ 5) — ไม่ใช่ตัวค้นหาชื่อ
- บันทึกฉบับ 7: เซิร์ฟเวอร์เขียนชื่อ + `__signer` ทับจากฉบับ 3/4 ทุกครั้ง (แบบที่ฉบับ 4/5 ทำ) กันยิง POST เปลี่ยนคนเซ็น
- `signersNamedInForm` ใช้ได้เลย — วนทุกช่องลงนามที่อยู่ใน `SIGNER_NAME_FIELDS` อ่าน `__signer` แล้วตรวจชื่อตรงบัญชี

### 4.4 ฉบับ 8 — ประธานผูกกับบัญชีเดียวกัน
- `SIGNER_NAME_FIELDS` ACADEMIC 8: `committee_president_name` → ผู้ลงนามคือประธานที่เลือกไว้ในฉบับ 3
- ส่ง `committee_president_name__signer` จาก `committee_1_name__signer`

### 4.5 กล่องข้อความในแม่แบบ
บล็อกลงนามของ `doc_7.docx` อยู่ในกล่องข้อความ (`mc:AlternateContent`) ที่ดูเหมือน "พิมพ์ซ้ำ 2 ชุด" คือสำเนา VML (`mc:Fallback`) ของกล่องเดียวกันที่ Word เขียนไว้ให้โปรแกรมรุ่นเก่า แสดงจริงแค่ชุดเดียว — **ไม่ต้องลบอะไร**
- การหา `<w:p>` ในกล่องข้อความรองรับอยู่แล้ว (`DocumentGenerationService.enclosingParagraph` — ฉบับ 6 มีแบบเดียวกัน) และประธานฉบับ 7 เซ็นผ่าน e2e อยู่แล้ว (`SigningCirculationBrowserTest`)
- ความเสี่ยงที่เหลือ: กล่องข้อความมีความสูงคงที่ ลายเซ็นเพิ่มอีก 2 รูปอาจดันบรรทัดล่างหลุดกล่อง (ถูกตัด) — ตรวจในงานที่ 0 ถ้าล้น ขยายกล่องใน Word หรือลดความสูงรูปลายเซ็นเฉพาะฉบับนี้

### 4.6 ข้อมูลเก่า
| สภาพ | ทำอะไร |
|---|---|
| ฉบับ 3 ยังไม่เวียน | ชื่อเดิมที่ตรงบัญชีเดียว → ตัวค้นหาเลือกให้อัตโนมัติ; ไม่ตรง → "ชื่อเดิม: X (ไม่พบในระบบ) กรุณาเลือกใหม่" |
| ฉบับ 3 ลงนามแล้ว แต่ไม่มี `__signer` | ส่งเวียนฉบับ 7 ใช้การจับคู่จากชื่อ (มีใน `signersNamedInForm` แล้ว) — ถ้าจับคู่ไม่ได้ เปิดตัวค้นหาชื่อในฉบับ 7 **เฉพาะช่องนั้น** (ชื่อที่พิมพ์ต้องตรงกับฉบับ 3) |
| ฉบับ 7 เวียน/ลงนามแล้ว (ประธานคนเดียว) | ไม่แตะ — ซองเดิมใช้ตำแหน่งลงนามตามตอนเปิดซอง |
