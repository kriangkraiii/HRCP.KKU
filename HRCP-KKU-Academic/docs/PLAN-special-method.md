# แผน: รองรับการขอตำแหน่งโดยวิธีพิเศษตามข้อบังคับ มข. พ.ศ. 2569

อ้างอิง: ข้อบังคับ มข. ว่าด้วยคุณสมบัติ หลักเกณฑ์ และวิธีการแต่งตั้งและถอดถอนผู้ดำรงตำแหน่งทางวิชาการ
สำหรับพนักงานมหาวิทยาลัย พ.ศ. 2569 ข้อ 15, 18 (และข้อ 32 สำหรับผลงานด้านอื่น), ข้อ 40 (ชะลอวิธีที่ 3)

## กติกาที่ต้องรองรับ

| ข้อ | กติกา |
|---|---|
| 18 วรรคหนึ่ง | วิธีพิเศษใช้เมื่อ (ก) ดำรงตำแหน่งไม่ครบระยะเวลา (ข) อาจารย์ขอ รศ. โดยไม่เคยเป็น ผศ. (ค) ขอต่างสาขา |
| 18.1 | ผศ. วิธีพิเศษ — เสนอผลงานเหมือนวิธีปกติ |
| 18.2 | รศ. วิธีพิเศษ — เสนอผลงานได้เฉพาะ **วิธีที่ 1** |
| 18.3 | ศ. วิธีพิเศษ — เสนอผลงานได้เฉพาะ **วิธีที่ 1** |
| 18.x | กรรมการ ≥ 3 คน เอกฉันท์ ระดับ B/A/A+ — ขั้นของมหาวิทยาลัยหลังวิทยาลัยส่งเรื่อง (นอกขอบเขตระบบ) |

ระบบรู้ได้เองเฉพาะกรณี (ข) และการข้ามขั้นไป ศ. — คือ "ข้ามขั้น" (ตำแหน่งที่ขอสูงกว่าปัจจุบัน ≥ 2 ขั้น)
กรณี (ก) และ (ค) ระบบไม่มีข้อมูลพอ ผู้ยื่นเลือก "พิเศษ" เอง

## ขั้นตอน

### 1. กติกากลาง — `AcademicRankPolicy`
- ถอด `evaluationTargetViolation` (ล็อกอาจารย์ → ผศ. ที่ขัดข้อ 18) กลับไปใช้ `rankViolation`
- `requiresSpecialMethod(current, target)` — ข้ามขั้น ≥ 2
- `isSpecial(method)` / `worksMethodViolation(method, target, worksMethod)` — วิธีพิเศษ + รศ./ศ. ต้องวิธีที่ 1
- เทสต์: `AcademicRankPolicyTest`

### 2. เฟส 1 — เอกสารที่ 1 ประเมินการสอน
- อาจารย์เลือก รศ. ได้อีกครั้ง (controller: `associateBlocked` เดิม, server `doc1RankProblem` → `rankViolation`)
- เลือก รศ. ขณะเป็นอาจารย์ → แสดงคำอธิบาย: วิธีพิเศษ ข้อ 18.2, ผลงานวิธีที่ 1 ระดับ A, ผลประเมินระดับชำนาญพิเศษ
- JS: อาจารย์ → ผศ./รศ. เลือกได้ (ค่าเริ่ม ผศ.), ผศ. → รศ. เท่านั้น, รศ. → ปิดทั้งคู่

### 3. เฟส 2 — `PositionRequestService`
- `requiresSpecialMethod(request)` — ตำแหน่งปัจจุบันลำดับเดียวกับ `submissionProblem`
- `lockedFields(request, 1)`: ข้ามขั้น → `method=พิเศษ` (+ `works_method=1` เมื่อขอ รศ./ศ.)
- `newDraft`: ข้ามขั้น → `evaluationMethod=พิเศษ`
- บันทึกเอกสารที่ 1 → sync `method` ไปที่ `request.evaluationMethod` (เดิม sync จากเอกสารที่ 2 ซึ่งไม่มีช่องนี้)
- `submissionProblem`: ด่านสุดท้ายสำหรับเอกสารเก่า — ข้ามขั้นแต่ไม่ใช่วิธีพิเศษ / วิธีพิเศษแต่ผลงานไม่ใช่วิธีที่ 1
  → error `special_method` + ข้อความในหน้าคำร้องและแดชบอร์ด

### 4. ความครบถ้วน — `DocumentCompleteness`
- `works_method` บังคับเฉพาะขอ รศ./ศ. (ผศ. ไม่มีวิธีที่)
- malformed: วิธีพิเศษ + รศ./ศ. + ผลงานไม่ใช่วิธีที่ 1 → ส่งลงนามไม่ได้

### 5. ฟอร์มเอกสารที่ 1 เฟส 2
- `method` และ `works_method` เป็น radio (select ทุกตัวถูก `select_to_datalist.js` แปลงเป็นช่องพิมพ์อิสระ)
- ล็อกจากระบบ → แสดงอ่านอย่างเดียวพร้อมเหตุผล
- เลือก "พิเศษ" เอง → ผลงานถูกตั้งเป็นวิธีที่ 1 และปิดวิธีที่ 2
- `works_method` แสดง/บังคับเฉพาะเมื่อขอ รศ./ศ. วิธีที่ 3 ไม่มีให้เลือก (ข้อ 40)

### 6. เอกสารที่พิมพ์
- p2doc_1 "(โดยวิธี{{method}})" → "ปกติ วิธีที่ ๑" เมื่อมีวิธีของผลงาน (`normalizePhase2`)
- p2doc_8 "โดยวิธีปกติ {{evaluation_method}}" พิมพ์ "วิธีปกติ พิเศษ" — แก้เทมเพลตเป็น "โดยวิธี{{evaluation_method}}"
  และ `Doc8AutoFill` ประกอบค่าเดียวกับเอกสารที่ 1
