### UC-POS-A03: อัพเดทสถานะ

| รายการ | รายละเอียด |
|--------|-----------|
| **รหัส Use Case** | UC-POS-A03 |
| **ชื่อ Use Case** | อัพเดทสถานะคำร้องตำแหน่ง |
| **คำอธิบาย** | เปลี่ยนสถานะคำร้องตำแหน่ง พร้อมระบุหมายเหตุ |

#### ลำดับเหตุการณ์หลัก

| ขั้นตอน | ผู้กระทำ | การกระทำ |
|---------|---------|---------|
| 1 | ผู้ดูแลระบบ | เลือกสถานะใหม่จาก dropdown |

| 5 | ระบบ | ส่ง email แจ้งผู้ยื่น |

#### กฎทางธุรกิจ
- สถานะเปลี่ยนตาม flow: DRAFT → DOCUMENT_RECEIVED → DOCUMENT_VERIFICATION → SCREENING_COMMITTEE → REVISION_REQUESTED / SCREENING_APPROVED → COLLEGE_COMMITTEE → COLLEGE_APPROVED → SENT_TO_HR (ดู [แผนภาพสถานะ](appendix-status-flows.md))

| 3 | ระบบ | ดึงข้อมูลคำร้อง + เอกสาร + completedDocs + status history |
| 4 | ระบบ | แสดง: ตารางเอกสาร (เฉพาะ APPLICANT_DOCS), สถานะ, ไทม์ไลน์ |

#### กฎทางธุรกิจ
- ผู้ยื่นเห็นเฉพาะเอกสาร APPLICANT_DOCS (1,2,3,4,6,7,9)
- docLabels ที่แสดงเป็นฝั่ง applicant (getApplicantDocLabels)

## 3. System Sequence Diagrams

### SSD-POS-01: ผู้ยื่นสร้างคำร้องตำแหน่ง

```mermaid
sequenceDiagram
    actor U as ผู้ยื่นคำร้อง

    participant DB as ฐานข้อมูล

    U->>S: GET /user/position/new-request
    S->>DB: ตรวจสอบ hasActiveRequest
    S->>DB: ตรวจสอบ draft ค้าง
    S->>DB: getEligibleEvaluations (Phase 1 ที่ผ่าน)
    DB-->>S: รายการผลประเมิน
    S-->>U: แสดงหน้าเลือกผลประเมิน

    U->>S: POST /user/position/create-request (evaluationId)
    S->>DB: createDraftRequest(user, evaluationId)
    DB-->>S: คำร้องตำแหน่ง (DRAFT)
    S-->>U: Redirect → /user/position/request/{id}
```

### SSD-POS-02: ผู้ยื่นกรอกเอกสาร

```mermaid
sequenceDiagram
    actor U as ผู้ยื่นคำร้อง
    participant S as ระบบ
    participant DB as ฐานข้อมูล

    U->>S: GET /user/position/request/{id}/document/{type}
    S->>S: ตรวจสอบ type ∈ APPLICANT_DOCS
    S->>DB: ดึง existing data
    S-->>U: แสดงฟอร์ม doc_form_{type}

    U->>S: POST /user/position/request/{id}/document/{type} (formData, action)
    S->>S: สร้าง JSON จาก formData
    alt action == draft
        S->>DB: saveDraft(request, type, json, label, APPLICANT)
        S-->>U: Redirect + "บันทึกแบบร่างสำเร็จ"
    else action == submit
        S->>DB: saveDocument(request, type, json, null, label, null, APPLICANT)
        S-->>U: Redirect + "บันทึกสำเร็จ"
    end
```

### SSD-POS-03: ผู้ยื่นส่งคำร้องตำแหน่ง

```mermaid
sequenceDiagram
    actor U as ผู้ยื่นคำร้อง
```

### SSD-POS-04: Admin อัพเดทสถานะ + กรอกเอกสาร

```mermaid
sequenceDiagram

    DG-->>S: filePath
    S->>DB: saveDocument(source=ADMIN)
    S-->>A: Redirect + "สร้างเอกสารสำเร็จ"
```
