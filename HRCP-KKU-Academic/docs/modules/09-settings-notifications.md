| ตัวเลือก | คำอธิบาย | ค่าเริ่มต้น |

| แจ้งเตือน 3 เดือนก่อนหมดอายุ | แจ้งเตือนผลประเมินก่อนหมดอายุ 3 เดือน | ปิด |
| แจ้งเตือน 1 เดือนก่อนหมดอายุ | แจ้งเตือนผลประเมินก่อนหมดอายุ 1 เดือน | ปิด |

| 4 | ระบบ | ดึงผู้ใช้ที่เปิดการแจ้งเตือนตามช่วงเวลา (6m/3m/1m/1w) |
| 5 | ระบบ | ส่งอีเมลแจ้งเตือนเฉพาะผู้ใช้ที่ตรงเงื่อนไข |

## 3. System Sequence Diagrams

### SSD-SET-01: บันทึกการตั้งค่า

```mermaid
sequenceDiagram
    actor U as ผู้ใช้
    participant S as ระบบ
    participant DB as ฐานข้อมูล

    U->>S: GET /user/academic/settings
    S->>DB: ดึงข้อมูลผู้ใช้ (การตั้งค่าปัจจุบัน)
    DB-->>S: UserDtls (autoDraft, emailNotification, expiryAlerts)
    S-->>U: แสดงหน้าตั้งค่า (toggle switches)

    U->>S: POST /user/academic/settings (autoDraftEnabled, emailNotificationEnabled, expiryAlert6m/3m/1m/1w)
    S->>DB: อัพเดท UserDtls
    DB-->>S: สำเร็จ
    S-->>U: Redirect + "บันทึกการตั้งค่าสำเร็จ"
```

### SSD-SET-02: ตรวจสอบและส่งแจ้งเตือนหมดอายุ

```mermaid
sequenceDiagram
    participant SC as Scheduler
    participant S as ระบบ
    participant DB as ฐานข้อมูล
    participant E as อีเมล

    SC->>S: เริ่มตรวจสอบ (scheduled)
    S->>DB: ดึงผลประเมินที่ยังไม่หมดอายุ
    DB-->>S: รายการผลประเมิน

    loop แต่ละผลประเมิน
        S->>S: คำนวณเวลาที่เหลือ
        S->>DB: ดึงผู้ใช้ที่เปิดแจ้งเตือนตามช่วงเวลา
        DB-->>S: รายชื่อผู้ใช้

        alt มีผู้ใช้ที่ตรงเงื่อนไข
            S->>E: ส่งอีเมลแจ้งเตือนหมดอายุ
        end
    end
```
